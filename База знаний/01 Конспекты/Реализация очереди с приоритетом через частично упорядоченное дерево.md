# Реализация очереди с приоритетом через частично упорядоченное дерево
Вместо полного порядка (как в BST) можно ослабить требования: потребовать, чтобы **приоритет родителя был не меньше (или не больше) приоритетов детей**. Этого достаточно для очереди с приоритетом, потому что нам не нужен поиск произвольного элемента — только доступ к максимуму (минимуму).

![[MAX-дерево.png]]
**Свойство кучи (heap property):** для каждого узла его значение больше или равно значениям его детей (для max-кучи).
