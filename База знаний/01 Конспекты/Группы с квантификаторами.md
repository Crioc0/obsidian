# Группы с квантификаторами
Квантификаторы применяются ко всей группе:

```js
const regex = /(ab)+/;  // одна или более последовательностей "ab"
console.log(regex.test("ab"));   // true
console.log(regex.test("abab")); // true
console.log(regex.test("abb"));  // false

const regex2 = /(cat|dog){2}/;  // cat или dog ровно 2 раза
console.log(regex2.test("catdog")); // true
console.log(regex2.test("dogcat")); // true
```
