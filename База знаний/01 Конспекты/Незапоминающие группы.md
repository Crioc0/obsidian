# Незапоминающие группы
Если группа нужна только для группировки, но не для захвата, используется `(?:...)`:

```js
// Запоминающие группы
const regex1 = /(cat|dog) (barks|jumps)/;
console.log("cat barks".match(regex1)[1]); // "cat"

// Незапоминающие группы
const regex2 = /(?:cat|dog) (?:barks|jumps)/;
console.log("cat barks".match(regex2)[1]); // undefined

// Группировка без захвата для квантификаторов
const regex3 = /(?:ab)+/;  // ab повторяется, но не запоминается
```
