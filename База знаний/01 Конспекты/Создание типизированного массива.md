# Создание типизированного массива

В конструкторе массива можно передать число, которое будет задавать длину создаваемого массива. Типизированный массив сразу инициализирует все элементы без дырок. В конструктор можно передать обычный или другой типизированный массив. C помощью .of создать массив на основе любого Iterable-объекта

```js
const set = new Set([1, 2, 3]); 
console.log(Int32Array.of(...set));
```
