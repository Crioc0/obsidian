# Дерево

**Дерево** — это иерархическая структура данных, состоящая из узлов (nodes), соединённых рёбрами. Основные характеристики:

- Есть **корень (root)** — единственный узел, у которого нет родителей.
- Каждый узел может иметь несколько **дочерних (children)** узлов.
- Узлы без дочерних называются **листьями (leaves)**.
- В дереве нет циклов.

![[Дерево.png]]
Деревья широко применяются в программировании: файловые системы, DOM, абстрактные синтаксические деревья (AST), маршрутизация, базы данных и многое другое.
