# Система продуктивности

Задачи разбиваются по крупным группам: обучение, работа, развитие. В них записываются все задачи из раздела входящие. Небольшие задачи либо выполнятся сразу, либо отправляются в раздел мелкие задачи. 
Есть раздел Активные проекты, куда отправляются задачи из крупных групп. Максимально может быть 5 активных проектов.
