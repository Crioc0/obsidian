# Итераторы

Итератор — это объект с методом `next()`, который возвращает `{ value, done }`.

```js
// Пример простого итератора
function createRange(start, end) {
    let current = start;
    return {
        next() {
            if (current <= end) {
                return { value: current++, done: false };
            }
            return { done: true };
        }
    };
}

const iterator = createRange(1, 3);
console.log(iterator.next()); // { value: 1, done: false }
console.log(iterator.next()); // { value: 2, done: false }
console.log(iterator.next()); // { value: 3, done: false }
console.log(iterator.next()); // { done: true }
```

Итераторы можно использовать и с циклами.

```js
// Массив через итератор
const arr = [1, 2, 3];
const arrIterator = arr.values();
for (let i = arrIterator.next(); !i.done; i = arrIterator.next()) {
    console.log(i.value);
}

// Set через итератор
const set = new Set([1, 2, 3]);
const setIterator = set.values();
for (let i = setIterator.next(); !i.done; i = setIterator.next()) {
    console.log(i.value);
}
```

Теперь обход работает единообразно: мы получаем итератор, вызываем `next()` в цикле и проверяем `done`. Но такой код громоздкий и захламляет логику — приходится вручную управлять вызовами `next()` и проверкой `done`.
