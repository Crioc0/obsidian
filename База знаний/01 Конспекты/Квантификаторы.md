# Квантификаторы

Квантификаторы указывают, сколько раз должно повторяться **предыдущее выражение**. Применяться могут к:

- **Одиночному символу** — `a+`
- **Символьному классу** — `[0-9]+`
- **Группе** — `(ab)+`
- **Набору в скобках** — `(cat|dog){2}`

|Квантификатор|Значение|Пример|
|---|---|---|
|`*`|0 или более раз|`a*` — любое количество `a`|
|`+`|1 или более раз|`a+` — одна или более `a`|
|`?`|0 или 1 раз|`a?` — `a` может быть или не быть|
|`{n}`|Ровно n раз|`a{3}` — ровно три `a`|
|`{n,}`|n или более раз|`a{2,}` — две и более `a`|
|`{n,m}`|от n до m раз|`a{2,4}` — от двух до четырёх `a`|

```js
// К одиночному символу
const regex1 = /a+/;   // одна или более a
console.log(regex1.test("a"));   // true
console.log(regex1.test("aaa")); // true
console.log(regex1.test(""));    // false

// К символьному классу
const regex2 = /[0-9]+/;   // одна или более цифр
console.log(regex2.test("123")); // true
console.log(regex2.test("abc")); // false

// К группе
const regex3 = /(ab)+/;   // одна или более последовательностей "ab"
console.log(regex3.test("ab"));    // true
console.log(regex3.test("abab"));  // true
console.log(regex3.test("abb"));   // false

// К альтернации
const regex4 = /(cat|dog){2}/;   // cat или dog, повторённые 2 раза
console.log(regex4.test("catdog"));  // true
console.log(regex4.test("dogcat"));  // true
console.log(regex4.test("catcat"));  // true
console.log(regex4.test("cat"));     // false
```

**Примеры использования:**

- `/\d{3}-\d{2}-\d{4}/` — номер SSN (XXX-XX-XXXX)
- `/^\s*$/` — пустая строка (только пробелы)
- `/(https?:\/\/)?\w+\.\w+/` — URL с опциональным http:// или https://

### Жадность квантификаторов

[](https://gist.github.com/kobezzza/b6141028dee283cc4b496c500fc49bff#%D0%B6%D0%B0%D0%B4%D0%BD%D0%BE%D1%81%D1%82%D1%8C-%D0%BA%D0%B2%D0%B0%D0%BD%D1%82%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%82%D0%BE%D1%80%D0%BE%D0%B2)

По умолчанию все квантификаторы **жадные** — захватывают максимально возможную строку. Можно сделать их **ленивыми** (минимальными), добавив `?`:

```js
const str = "<div><span>Text</span></div>";

// Жадный — захватывает максимально
const greedy = /<.*>/;
console.log(str.match(greedy)); // "<div><span>Text</span></div>"

// Ленивый — захватывает минимально
const lazy = /<.*?>/;
console.log(str.match(lazy)); // "<div>"
```
