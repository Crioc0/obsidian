# Опциональная группа. undefined если не найдена
Если группа опциональна (с `?`), она может отсутствовать:

```js
const regex = /(cat)? (dog)/;
const match = "dog".match(regex);
console.log(match[0]); // "dog"
console.log(match[1]); // undefined — группа не найдена
console.log(match[2]); // "dog"
```
