# Автоматы (state machine)
**Автомат (конечный автомат)** — математическая модель, описывающая систему с конечным числом состояний и переходами между ними.

**Компоненты:**

- Множество состояний (Q).
- Алфавит (Σ) — множество допустимых входных символов.
- Функция переходов (δ: Q × Σ → Q).
- Начальное состояние (q0).
- Множество финальных состояний (F).
