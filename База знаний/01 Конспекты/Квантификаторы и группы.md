# Квантификаторы и группы
При повторении группы запоминается **последнее** совпадение:

```js
const regex = /(ab)+/;
const match = "ababab".match(regex);
console.log(match[1]); // "ab" — последнее совпадение группы
// Полное совпадение (match[0]) — "ababab"
```
