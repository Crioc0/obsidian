# Побитовые операторы

С помощью побитовых операторов возможно работать с байтами напрямую. По сути своей, любое "сложное вычисление" строится из комбинации побитовых операторов. Это самые быстрые операции для процессора. C прикладной точки зрения, чтение отдельных бит в рамках байта – наиболее частая задача для побитовых операторов. В JS они поддерживаются только числовыми типами. Тип number всегда приводится к Int32/Uint32

Пример: узнаем знак числа
```js
function isNegative(num) { 
	return (num & (1 << 31)) !== 0; 
} 

console.log(isNegative(42)); // false 
console.log(isNegative(-42)); // true
```
