# Кортежи

Кортеж - фундаментальная структура данных. Реализуются также, как и структуры, но вместо символический имен свойств используются индексы. Кортежи можно сравнить с гетерогенным массивом, где тип каждого элемента описан в схеме
```rust
fn main() { 
	struct RGBA(u8, u8, u8, u8); 
	let black = RGBA(0, 0, 0, 1); 
	println!("Black is {} {} {} {}!", black.0, black.1, black.2, black.3); }
```
