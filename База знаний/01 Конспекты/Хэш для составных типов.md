# Хэш для составных типов
Для составных ключей (массивы, объекты) нужно хэшировать все компоненты. Например, для точки `(x, y)` можно вычислить `hash = x * 31 + y`.

В JavaScript поведение хэширования для объектов определяется движком, но при использовании `Map` с объектами в качестве ключей используется сравнение по ссылке, а не по содержимому.
