# Ассоциативные массивы

Ассоциативные массивы - это массивы, в котором вместо числовых индексов используются ключи. Технически ключом может быть любое значение, соответствующее контрактам конкретной реализации такого массива. Контракты частично совпадают с обычными массивами. Элементы должны быть одного типа (или размера)(в js может быть разных типов и размеров благодаря динамической типизации).В ассоциативный массив можно добавлять в новые элементы и обходить их в цикле.

```js
const bob = new Map([["name", "Bob"], ["age", 22]]); // Вместо числового индекса используется "ключ" 

console.log(bob.get("name")); // В JS благодаря динамической типизации можно использовать разные типы 

console.log(bob.get("age")); 

bob.set("skills", ["sing", "code"]); 

bob.forEach((value, key) => { console.log(key, value); });
```
