# Именованные группы
Именованные группы позволяют обращаться к группе по имени, а не по номеру:

```js
const regex = /(?<animal>cat|dog) (?<action>barks|jumps)/;
const match = "cat barks".match(regex);
console.log(match.groups.animal); // "cat"
console.log(match.groups.action); // "barks"
```

**Синтаксис:** `(?<имя>...)`

**Важно:** именованные группы также доступны **по индексу** (как обычные группы), что полезно для обратной совместимости:

```js
const regex = /(?<animal>cat|dog) (?<action>barks|jumps)/;
const match = "cat barks".match(regex);
console.log(match[1]); // "cat" — доступ по индексу
console.log(match[2]); // "barks" — доступ по индексу
console.log(match.groups.animal); // "cat" — доступ по имени
console.log(match.groups.action); // "barks" — доступ по имени
```

## Две группы с одинаковым именем в разных альтернациях


Имя группы может использоваться в разных альтернативах:

```js
const regex = /(?<animal>cat|dog) (?<action>barks|jumps|runs)/;
// Группа animal — cat или dog
// Группа action — barks или jumps или runs
```
