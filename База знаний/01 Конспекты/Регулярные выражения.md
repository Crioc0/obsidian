# Регулярные выражения

**Регулярное выражение (regexp)** — это последовательность символов, задающая шаблон для поиска в тексте. Оно описывает **регулярный язык** — самый простой класс языков в иерархии Хомского.

## Простейшее регулярное выражение

Простейшее регулярное выражение — это обычный текст:

```js
// Найти подстроку "cat" в строке
const regex = /cat/;
console.log(regex.test("The cat is here")); // true
console.log(regex.test("The dog is here")); // false
```

Такое выражение совпадает с точным текстом "cat".
