# Обход коллекций

В JavaScript существует множество коллекций: массивы, строки, Map, Set, NodeList, arguments и другие. Для каждой из них можно перебрать элементы, но у каждой свой способ доступа:

```js
const arr = ['a', 'b', 'c'];
for (let i = 0; i < arr.length; i++) {
    console.log(arr[i]);
}

const str = 'hello';
for (const char of str) {
    console.log(char); // h, e, l, l, o
}

const text = 'hello 123 world 456';
let match;
const regex = /\d+/;
while ((match = regex.exec(text)) !== null) {
    console.log(match[0]); // "123", "456"
}

// Object — через for...in (перечисляемые свойства)
const obj = {a: 1, b: 2, c: 3};
for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
        console.log(key, obj[key]);
    }
}
```

Почему так происходит: коллекции по-разному устроены в памяти и на уровне API. Массив — непрерывная область памяти с доступом по индексу. Строка — последовательность с учётом кодировки. Set — хэш-таблица с уникальными значениями. Map — хэш-таблица с парами ключ-значение. Для каждой структуры требуется свой способ обхода.
