# Символьные классы

JavaScript предоставляет встроенные символьные классы для часто используемых наборов:

|Символ|Значение|
|---|---|
|`.`|Любой символ, кроме новой строки|
|`\d`|Цифра (0-9)|
|`\D`|Не цифра|
|`\w`|Словесный символ (буква, цифра, _)|
|`\W`|Не словесный символ|
|`\s`|Пробельный символ|
|`\S`|Не пробельный символ|
|`\b`|Граница слова|
|`\B`|Не граница слова|

```js
const regex = /\d+/;    // одна или более цифр
const regex2 = /\s+/;   // пробельные символы
const regex3 = /\w+/;   // слово
```

### Экранирование спецсимволов

[](https://gist.github.com/kobezzza/b6141028dee283cc4b496c500fc49bff#%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5-%D1%81%D0%BF%D0%B5%D1%86%D1%81%D0%B8%D0%BC%D0%B2%D0%BE%D0%BB%D0%BE%D0%B2)

Спецсимволы нужно экранировать обратным слешем `\`:

```js
const regex = /\\./;    // точка (любой символ, экранированный \.)
const regex2 = /\\/;    // обратный слеш
const regex3 = /\*/;    // звёздочка
```

**Список спецсимволов:** `\ ^ $ . * + ? ( ) [ ] { } |`

### Якорные символы

[](https://gist.github.com/kobezzza/b6141028dee283cc4b496c500fc49bff#%D1%8F%D0%BA%D0%BE%D1%80%D0%BD%D1%8B%D0%B5-%D1%81%D0%B8%D0%BC%D0%B2%D0%BE%D0%BB%D1%8B)

Якорные символы **не совпадают с символами**, а указывают на **позиции** в строке — начало, конец или границы слов.

|Символ|Значение|Описание|
|---|---|---|
|`^`|Начало строки|Совпадает с позицией перед первым символом строки|
|`$`|Конец строки|Совпадает с позицией после последнего символа строки|
|`\b`|Граница слова|Совпадает с позицией между `\w` и `\W` (или началом/концом строки)|

**Начало и конец строки:**

```js
const regex1 = /^Hello/;   // строка должна начинаться с Hello
console.log(regex1.test("Hello world")); // true
console.log(regex1.test("Say Hello"));   // false

const regex2 = /world$/;   // строка должна заканчиваться на world
console.log(regex2.test("Hello world")); // true
console.log(regex2.test("world Hello")); // false

// Комбинация — строка должна полностью соответствовать шаблону
const regex3 = /^Hello world$/;
console.log(regex3.test("Hello world")); // true
console.log(regex3.test("Hello world!")); // false
```

**Граница слова `\b`:**

`\b` совпадает с позицией между символами, где одна сторона — `\w` (буква, цифра, подчёркивание), а другая — `\W` (не буква/цифра/подчёркивание) или граница строки.

```js
// Ищет отдельное слово "cat"
const regex = /\bcat\b/;
console.log(regex.test("cat"));     // true
console.log(regex.test("the cat")); // true (граница перед и после)
console.log(regex.test("catdog"));  // false (нет границы после cat)
console.log(regex.test("concatenate")); // false (нет границы)

// \B — не граница слова (слово внутри другого слова)
const regex4 = /\Bcat\B/;
console.log(regex4.test("concatenate")); // true (cat внутри слова)
console.log(regex4.test("the cat"));     // false
```

**Важно:** при использовании с флагом `m` (multiline) `^` и `$` совпадают с началом и концом **каждой строки**, а не всей
