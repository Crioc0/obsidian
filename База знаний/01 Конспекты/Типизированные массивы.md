# Типизированные массивы

**Typed Arrays** — это механизм для работы с бинарными и числовыми данными в JavaScript. Они позволяют интерпретировать буфер памяти как массив чисел определённого типа.
«Снаружи» у нас есть только number и bigint – значит любое число «читаемое» из такого массива будет преобразовано в один из двух типов. При записи в такой массив числа – оно будет конвертироваться во внутреннее представление. Типизированный массив - это непрерывный набор переменных одного типа размера. Вся память при создании размечается нулями. Никаких ссылок нет- элементы всегда хранят свое значение в самом массиве.

Можно точно контролировать расход памяти, а строгий контракт на хранение элементов позволяет лучше оптимизировать работу кэша, JIT и сборщика мусора. Простота реализации позволяет легко передавать такие массивы в другие потоки/процессы или по сети без сериализации.

Можно прочитать любой бинарный файл как типизированный массив, что позволяет на стороне JS работать со сторонними бинарными форматами

**Основные типы:**

- `Int8Array`, `Uint8Array`, `Uint8ClampedArray` — 8-битные целые
- `Int16Array`, `Uint16Array` — 16-битные целые
- `Int32Array`, `Uint32Array` — 32-битные целые
- `Float16Array`,`Float32Array`, `Float64Array` — числа с плавающей точкой
- `BigInt64Array`, `BigUint64Array` — 64-битные bigint

```js
// Создание типизированного массива
const bytes = new Uint8Array([0, 255, 128]);
console.log(bytes[1]); // 255

// Работа с буфером
const buffer = new ArrayBuffer(16);       // 16 байт памяти
const int32View = new Int32Array(buffer); // 4 элемента по 4 байта
int32View[0] = 42;
console.log(int32View[0]); // 42

// Переиспользование буфера с другим типом
const uint16View = new Uint16Array(buffer);  // 8 элементов по 2 байта
console.log(uint16View[0]); // 42 (младшие 2 байта)
```

В JS всего 2 числовых типа: number и bigint. Если мы читаем некоторый элемент массива, то он будет автоматически преобразован в один из двух типов (в bigint из BigInt64Array/BigUint64Array)

```js
const arr = new Float32Array([1.23, 4.2, 0]); 
// float32 будет преобразован в number, который мы уже прочитаем
 console.log(arr[0]); 
 // number будет преобразован в float32, 
 // который уже будет храниться в памяти массива 
 arr[0] = 2.3;
```

## Преимущества типизированных массивов

1. **Производительность:** операции близки к C-подобным языкам
2. **Экономия памяти:** нет накладных расходов на хранение объектов
3. **Бинарная совместимость:** идеально для работы с файлами, сетевыми протоколами, WebGL, WebAudio
4. **Предсказуемое поведение:** нет SMI/HeapNumber неожиданностей

**Применение:**

- Обработка изображений (Canvas, WebGL)
- Аудио и видео (WebAudio, WebRTC)
- Бинарные протоколы (WebSocket, файлы)
- Научные вычисления (передача данных в WebAssembly)
- Игровые движки
