# Управляющие последовательности (escape sequences)
Это специальные символы, которые обозначаются через обратный слеш и используются для представления непечатаемых или служебных символов:

|Последовательность|Значение|
|---|---|
|`\n`|Перевод строки (LF)|
|`\r`|Возврат каретки (CR)|
|`\t`|Табуляция|
|`\v`|Вертикальная табуляция|
|`\f`|Подача страницы (form feed)|
|`\xHH`|Символ по шестнадцатеричному коду HH|
|`\uHHHH`|Символ по Unicode-коду HHHH (4 цифры)|
|`\u{HHHH}`|Символ по Unicode-коду (с флагом u)|

```js
// Перевод строки и табуляция
console.log("Строка\nс переносом");
// Вывод:
// Строка
// с переносом

// Unicode-символы
const regex = /\u00A9/; // знак копирайта ©
console.log(regex.test("©")); // true
```
