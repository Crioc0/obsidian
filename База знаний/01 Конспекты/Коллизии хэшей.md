# Коллизии хэшей
**Коллизия** — ситуация, когда два разных ключа дают одинаковый индекс в массиве.

Причины:

- Количество возможных ключей бесконечно (или очень велико), а размер таблицы ограничен.
- Хэш-функция не идеальна.

Коллизии неизбежны из-за принципа Дирихле (принципа ящиков): если N ящиков и N+1 предмет, хотя бы в одном ящике окажется два предмета.

## Ключи должны быть сравнимыми для обработки коллизий


При разрешении коллизий (особенно в методе цепочек) недостаточно просто найти ячейку по индексу — нужно перебрать все элементы в бакете и сравнить ключи на равенство. Поэтому хэш-таблица требует, чтобы ключи поддерживали операцию сравнения на равенство.

## Разрешение коллизий: метод цепочек

**Метод цепочек (chaining)** — самый распространённый способ. В каждой ячейке массива хранится не одно значение, а связный список (или другой контейнер) всех пар ключ-значение, попавших в эту ячейку.

```js
// Схематичная реализация
class HashTable {
    constructor(size = 100) {
        this.buckets = new Array(size).fill(null).map(() => []);
    }

    _hash(key) {
        let hash = 0;
        for (let i = 0; i < String(key).length; i++) {
            hash = (hash + String(key).charCodeAt(i)) % this.buckets.length;
        }
        return hash;
    }

    set(key, value) {
        const index = this._hash(key);
        const bucket = this.buckets[index];
        const existing = bucket.find(item => item.key === key);
        if (existing) {
            existing.value = value;
        } else {
            bucket.push({key, value});
        }
    }

    get(key) {
        const index = this._hash(key);
        const bucket = this.buckets[index];
        const item = bucket.find(item => item.key === key);
        return item ? item.value : undefined;
    }
}
```
