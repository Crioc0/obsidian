# Хэш-функции

**Хэш-функция** — это функция, которая преобразует входные данные (ключ) в целое число (хэш, дайджест). Требования к хэш-функции:

- **Детерминированность** — одинаковый ключ всегда даёт одинаковый хэш.
- **Равномерность** — хэши распределены по диапазону примерно равномерно (чтобы избежать коллизий).
- **Быстрота** — вычисление должно быть быстрым (иначе теряется смысл хэш-таблицы).

```js
// Простейшая хэш-функция для строк
function simpleHash(str, tableSize) {
    let hash = 0;
    for (let i = 0; i < str.length; i++) {
        hash = (hash + str.charCodeAt(i)) % tableSize;
    }
    return hash;
}
```

Общий смысл таких функций – это принять набор байт произвольного размера и выдать некоторый другой набор фиксированного размера. Для одного и того же набора результат должен быть всегда один и тот же. Изменение даже одного бита должно приводить к другому результату
