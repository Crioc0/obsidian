# Нумерация вложенных групп
Группы нумеруются **слева направо** по открывающей скобке:

```js
const regex = /((cat|dog) (barks|jumps))/;
// Группа 1: (cat|dog) (barks|jumps) — внешняя
// Группа 2: (cat|dog) — первая внутренняя
// Группа 3: (barks|jumps) — вторая внутренняя
```

**Правило:** номер группы определяется порядком открывающей скобки `(`.
