# Парсинг

Процесс десеариализации часто называется парсингом, хотя парсинг по сути - это процесс анализа содержимого в некотором формате для последующей обработки.

Когда мы загружаем исходный код в компилятор или VM, то он приходит как обычный текст, а затем уже разбирается на части. После происходит процесс проверки ошибок и построения структур для дальнейшей работы.

```js
// Парсинг JSON — анализ строки и построение объекта
function naiveParseJSON(jsonString) {
    // В реальности парсер делает гораздо больше:
    // 1. Лексический анализ — разбивает строку на токены
    // 2. Синтаксический анализ — проверяет правильность структуры
    // 3. Построение AST (абстрактного синтаксического дерева)
    // 4. Преобразование AST в объекты языка
    return JSON.parse(jsonString);  // это и есть парсинг
}

// Парсинг CSV — разбиение на строки и столбцы
function parseCSV(csvString) {
    const lines = csvString.split("\n");
    const headers = lines[0].split(",");
    const result = [];
    for (let i = 1; i < lines.length; i++) {
        const values = lines[i].split(",");
        const row = {};
        headers.forEach((header, idx) => {
            row[header] = values[idx];
        });
        result.push(row);
    }
    return result;  // распарсили CSV в массив объектов
}
```
