# Сегменты памяти для данных

Помимо основных сегментов стек и куча, есть еще сегменты для хранения данных, например, таких, которые имеют глобальную область видимости, размер которых известен, которые могут быть неизменяемыми. Как пример, литералы строк. Для них есть еще область памяти. В данном примере представление виртуальной памяти программы Linux
