# Контекстно-свободные грамматики

**Контекстно-свободные грамматики (КС-грамматики)** — более мощный класс, чем регулярные. Они позволяют описывать **вложенные структуры**.

**Отличие от регулярных:** в КС-грамматиках нетерминал может раскрываться в произвольную строку терминалов и нетерминалов, независимо от контекста.

**Примеры:**

- Арифметические выражения (вложенные скобки).
- Языки программирования (вложенные блоки).
- JSON (вложенные объекты и массивы).

```js
Пример КС-грамматики для арифметических выражений:
expr → expr '+' term | expr '-' term | term
term → term '*' factor | term '/' factor | factor
factor → '(' expr ')' | number
number → digit number | digit
```

**Магазинный автомат (pushdown automaton)** — это конечный автомат, дополненный **стековой памятью**. Он используется для распознавания контекстно-свободных языков.

**Как работает:**

1. Автомат читает символы по одному.
2. В зависимости от текущего состояния, символа и вершины стека:
    - Переходит в новое состояние.
    - Кладёт/убирает символы из стека.
3. Если вся строка прочитана и стек пуст — строка корректна.

**Пример: проверка сбалансированных скобок:**

- `(())` — корректно.
- `(()` — не корректно.

Магазинный автомат может проверить корректность, используя стек для хранения открытых скобок.

## Пример грамматики JSON

JSON — пример языка, описываемого контекстно-свободной грамматикой:

```js
json → value
value → object | array | string | number | 'true' | 'false' | 'null'
object → '{' [pair {',' pair}] '}'
pair → string ':' value
array → '[' [value {',' value}] ']'
string → '"' char {char} '"'
number → '-'? digits ['.' digits] [exponent]
```

Эта грамматика описывает вложенные структуры: объекты и массивы могут содержать любые значения, включая другие объекты и массивы.
