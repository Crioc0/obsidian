# Флаги компиляции регулярных выражений

|Флаг|Название|Описание|
|---|---|---|
|`g`|global|Глобальный поиск всех совпадений|
|`i`|ignoreCase|Игнорирование регистра|
|`m`|multiline|Многострочный режим (`^` и `$` для каждой строки)|
|`u`|unicode|Поддержка Unicode (суррогатные пары, `\p{...}`)|
|`y`|sticky|Поиск только с позиции `lastIndex`|
|`s`|dotAll|Символ `.` совпадает с `\n`|
|`v`|unicodeSets|Расширенный Unicode (ES2024)|

## Флаг g (global)

`g` позволяет найти все совпадения в строке, а не только первое.

```js
const str = "cat dog cat";
const regex = /cat/g;
console.log(str.match(regex)); // ["cat", "cat"]
console.log(str.replace(regex, "bird")); // "bird dog bird"
```

## Нюансы test с флагом g

`test()` с флагом `g` изменяет `lastIndex` при каждом вызове:

```js
const regex = /cat/g;
console.log(regex.test("cat")); // true
console.log(regex.lastIndex); // 3
console.log(regex.test("cat")); // false (поиск с позиции 3)
console.log(regex.lastIndex); // 0 (сброс)
```

## Нюансы match с флагом g

[](https://gist.github.com/kobezzza/b49c08a4bb35f0256fc154a14ce4f4b5#%D0%BD%D1%8E%D0%B0%D0%BD%D1%81%D1%8B-match-%D1%81-%D1%84%D0%BB%D0%B0%D0%B3%D0%BE%D0%BC-g)

`match()` с `g` возвращает массив всех совпадений, **без групп**:

```js
const regex = /(ca)t/g;
const str = "cat cat";
console.log(str.match(regex)); // ["cat", "cat"] — группы потеряны!
```

Для получения групп используйте `matchAll()`.

## Нюансы replace с флагом g

`replace()` с `g` заменяет все совпадения:

```js
console.log("cat cat".replace(/cat/g, "dog")); // "dog dog"
console.log("cat cat".replace(/cat/, "dog"));  // "dog cat"
```

## Нюансы matchAll с флагом g

`matchAll()` возвращает итератор по всем совпадениям с группами:

```js
const regex = /(ca)t/g;
const matches = "cat cat".matchAll(regex);
for (const match of matches) {
    console.log(match[0]); // "cat"
    console.log(match[1]); // "ca"
}
```

## Флаг i (ignore case)

Игнорирует регистр символов:

```js
console.log(/cat/i.test("CAT")); // true
console.log(/cat/i.test("Cat")); // true
```

## Флаг m (multiline)

[](https://gist.github.com/kobezzza/b49c08a4bb35f0256fc154a14ce4f4b5#%D1%84%D0%BB%D0%B0%D0%B3-m-multiline)

В многострочном режиме `^` и `$` совпадают с началом и концом КАЖДОЙ строки:

```js
const str = "cat\ndog";
console.log(/^dog/.test(str));    // false (ищем в начале всей строки)
console.log(/^dog/m.test(str));   // true (ищем в начале строки)
```

## Флаг u (unicode)

Включает поддержку Unicode: суррогатные пары считаются одним символом, работают свойства `\p{...}`.

```js
console.log(/^.$/.test("😀"));   // false (суррогатная пара — 2 символа)
console.log(/^.$/u.test("😀"));  // true (один символ)
```

### Символьный класс \p{...}

Доступен только с флагом `u`:

```js
console.log(/\p{Script=Cyrillic}/u.test("А")); // true
console.log(/\p{Emoji}/u.test("😀"));          // true
console.log(/\p{Digit}/u.test("5"));           // true
```

**Популярные свойства:**

- `\p{Script=Cyrillic}` — кириллица.
- `\p{Emoji}` — эмодзи.
- `\p{Digit}` — цифры.
- `\p{Letter}` — буквы.
- `\p{Punctuation}` — пунктуация.

## Флаг y (sticky)

Поиск **только** с позиции `lastIndex`. Если на этой позиции нет совпадения — поиск завершается.

```js
const regex = /cat/y;
regex.lastIndex = 3;
console.log(regex.test("cat cat")); // true (начинаем с пробела, cat нет)
console.log(regex.lastIndex); // 0 (сброс при неудаче)

regex.lastIndex = 4;
console.log(regex.test("cat cat")); // true (начинаем с cat)
```

## Совмещение g и y

`g` и `y` можно комбинировать:

```js
const regex = /cat/gy;
regex.lastIndex = 4;
console.log(regex.test("cat cat")); // true
console.log(regex.test("cat cat")); // false (поиск с 7, cat нет)
```

## Флаг s (dotAll)

Символ `.` совпадает с переводом строки:

```js
const str = "cat\ndog";
console.log(/cat.dog/.test(str));  // false (точка не совпадает с \n)
console.log(/cat.dog/s.test(str)); // true
```

## Флаг v (unicodeSets)

Новый флаг `v` (ES2024) расширяет возможности `u`:

- Поддержка разности множеств: `[A-Z--C]` (A-Z без C).
- Поддержка пересечения: `[A-Z&&[^C]]`.
- Вложенные символьные классы.

```js
// ES2024
console.log(/[A-Z--C]/v.test("A")); // true
console.log(/[A-Z--C]/v.test("C")); // false
```
