# Альтернация в регулярных выражениях
Альтернация позволяет выбрать один из вариантов:

```js
const regex = /cat|dog/;
console.log(regex.test("cat")); // true
console.log(regex.test("dog")); // true
console.log(regex.test("bird")); // false
```
