# Группировка в регулярных выражениях

Круглые скобки в регулярных выражениях выполняют две основные функции:

**1. Группировка для применения квантификаторов и альтернаций**

Скобки позволяют применять операторы `*`, `+`, `?`, `{n,m}` и альтернацию (`|`) ко всей группе, а не к одному символу:

```js
// Без группировки: квантификатор применяется только к 'a'
const regex1 = /ab+/;  // a + одна или более 'b'

// С группировкой: квантификатор применяется ко всей группе 'ab'
const regex2 = /(ab)+/; // одна или более последовательностей 'ab'

// Локальная альтернация — альтернатива только внутри группы
const regex3 = /(cat|dog) (barks|jumps)/;
// Ищет: cat или dog, затем пробел, затем barks или jumps
```

```js
console.log(regex2.test("ab"));   // true
console.log(regex2.test("abab")); // true
console.log(regex2.test("abb"));  // false (нужна последовательность 'ab')

console.log(regex3.test("cat barks")); // true
console.log(regex3.test("dog jumps")); // true
console.log(regex3.test("bird walks")); // false
```

**2. Захват подстрок**

По умолчанию группы также **захватывают** (сохраняют) совпавший текст, который можно получить через индексы после совпадения. Это полезно для извлечения частей строки.

```js
const regex = /(cat|dog) (barks|jumps)/;
const match = "cat barks".match(regex);
console.log(match[0]); // "cat barks" — полное совпадение
console.log(match[1]); // "cat" — первая группа
console.log(match[2]); // "barks" — вторая группа
```
