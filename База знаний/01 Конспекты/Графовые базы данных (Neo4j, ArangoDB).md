# Графовые базы данных (Neo4j, ArangoDB)
Графовые базы данных хранят данные как вершины и рёбра, оптимизируя операции обхода.

- **Neo4j** — самая популярная. Использует язык запросов Cypher.
- **ArangoDB** — мультимодельная (документы + графы).
- **TigerGraph, JanusGraph, Dgraph** — другие представители.

**Когда нужны графовые БД:** когда важны связи между данными (соцсети, системы рекомендаций, fraud detection, управление зависимостями).

```cypher
// Пример запроса в Neo4j: друзья друзей
MATCH (user:User {name: "Alice"})-[:FRIEND_OF*2]->(friend)
RETURN friend.name
```

**Сравнение с реляционными БД:** в реляционных связь через JOIN-ы становится дорогой при большой глубине. Графовые БД хранят рёбра как физические ссылки, что делает обходы быстрыми независимо от глубины.
