# Языки описания шаблонов

Поиск по шаблону — одна из фундаментальных задач обработки текста. Вместо того чтобы писать сложные алгоритмы для каждого конкретного случая, существуют **языки описания шаблонов** — DSL (Domain Specific Language), позволяющие компактно и выразительно описывать, что именно нужно найти в тексте.

## Что такое DSL

**DSL (Domain Specific Language)** — язык, созданный для решения задач в конкретной предметной области. В отличие от универсальных языков (JavaScript, Python, C++), DSL узкоспециализирован и позволяет более лаконично выражать решения.

**Примеры DSL:**

- Регулярные выражения — для поиска в тексте.
- SQL — для работы с базами данных.
- CSS — для описания стилей.
- HTML — для разметки документов.

## Регулярные выражения как DSL в JavaScript

Регулярные выражения в JavaScript — это встроенный DSL для работы с текстом. Они позволяют:

- Проверять, соответствует ли строка шаблону.
- Находить подстроки, соответствующие шаблону.
- Заменять части строки.
- Разбивать строку по шаблону.
