# Наборы символов в квадратных скобках

Квадратные скобки задают **символьный класс** — один символ из перечисленных:

```js
const regex = /[aeiou]/; // любая гласная
console.log(regex.test("a")); // true
console.log(regex.test("b")); // false
```

### Исключающие наборы: `[^]`

Символ `^` внутри квадратных скобок инвертирует набор:

```js
const regex = /[^aeiou]/;     // любой символ, кроме гласных
console.log(regex.test("b")); // true
console.log(regex.test("a")); // false
```

### Диапазоны внутри символьного набора

Можно указать диапазоны символов:

```js
const regex = /[a-z]/;    // любая строчная буква латиницы
const regex2 = /[0-9]/;   // любая цифра
const regex3 = /[A-Za-z]/; // любая буква латиницы
```

**Важно:** диапазоны в регулярных выражениях JavaScript работают на основе **кодовых точек Unicode**.

```js
// Диапазон работает по кодам Unicode
console.log("a".charCodeAt(0)); // 97
console.log("z".charCodeAt(0)); // 122
// [a-z] — все символы с кодами от 97 до 122
```

**Проблема с кириллицей:**

```js
const regex = /[а-я]/; // кириллица от а до я
console.log(regex.test("а")); // true
console.log(regex.test("я")); // true
console.log(regex.test("ё")); // false! ❌
```

**Почему так происходит:** в Unicode буква `ё` (U+0451) находится **отдельно** от остальных кириллических букв (U+0410–U+044F, где `я` — U+044F). Диапазон `[а-я]` не включает `ё`.

**Решения:**

1. Явно добавить букву `ё`:

    ```js
    const regex = /[а-яё]/;
 console.log(regex.test("ё")); // true
    ```

2. Использовать Unicode-свойства (с флагом u):

    ```js
    const regex = /\p{Script=Cyrillic}/u; // все кириллические символы
    console.log(regex.test("а")); // true
    console.log(regex.test("ё")); // true
    console.log(regex.test("А")); // true
    ```
