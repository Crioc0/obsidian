# Маршалинг и демаршалинг данных

Маршалингом называется процесс преобразования данных из памяти программы в формат, пригодный для сохранения на диске или передаче по сети.

Демаршалинг - это обратный процесс с восстановлением памяти программы через чтение такого файла.

```js
// Исходный объект в памяти программы
const user = {
    name: "Alice",
    createdAt: new Date("2024-01-01")
};

// МАРШАЛИНГ — превращаем в строку для передачи
const marshalled = JSON.stringify(user);
// "{"name":"Alice","createdAt":"2024-01-01T00:00:00.000Z"}"

// ДЕМАРШАЛИНГ — обратное преобразование (простое)
const unmarshalled = JSON.parse(marshalled);
// { name: "Alice", createdAt: "2024-01-01T00:00:00.000Z" }
```

Важное отличие: демаршалинг не восстанавливает типы. `createdAt` стал строкой, а не объектом Date.
