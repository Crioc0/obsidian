# Реализация очереди с приоритетом через сбалансированные деревья поиска

Сбалансированное дерево (AVL, красно-чёрное) может хранить пары `(приоритет, значение)`, упорядоченные по приоритету.

- **Вставка** — O(log n) (стандартная вставка в дерево).
- **Извлечение максимума** — O(log n) (найти самый правый узел и удалить его).

**Плюсы:** хорошая асимптотика, возможность произвольного доступа по приоритету. **Минусы:** сложность реализации, накладные расходы на поддержание баланса, дополнительная память под ссылки.
