# Коллекторы итераторов

**Коллекторы** — это методы или конструкции, которые "собирают" все значения из итерируемого (Iterable) объекта и возвращают готовую структуру. Они терминальные и потребляют весь итератор.

**Главная идея:** итератор сам не знает, в какую коллекцию его нужно собрать. Это решает потребитель — тот, кто вызывает терминальную операцию или передаёт итерируемый объект в конструктор/функцию.

```js
// Строка — это Iterable
const data = "abcdef";

// В массив
const arr = Array.from(data); // ['a', 'b', 'c', 'd', 'e', 'f']

// В Set (уникальные значения)
const set = new Set(data); // Set {'a', 'b', 'c', 'd', 'e', 'f'}

// В Map — сначала преобразуем через map, затем собираем в Map
const map = new Map(
    Iterator.from(data).map((char, index) => [char, index]) // ['a', 0], ['b', 1], ...
); // Map {'a' => 0, 'b' => 1, 'c' => 2, 'd' => 3, 'e' => 4, 'f' => 5}
```

**Коллекторы в стандартной библиотеке:**

|Конструкция|Что делает|Пример|
|---|---|---|
|`Array.from(iterable)`|Собирает в массив|`Array.from(iterator)`|
|`new Set(iterable)`|Собирает в Set (уникальные)|`new Set(iterator)`|
|`new Map(iterable)`|Собирает в Map (пары)|`new Map(iterator)`|
|`Promise.all(iterable)`|Собирает результаты промисов|`Promise.all(iterator)`|
|`Promise.race(iterable)`|Ждёт первый промис|`Promise.race(iterator)`|
|`Promise.allSettled(iterable)`|Ждёт все промисы|`Promise.allSettled(iterator)`|
|`Promise.any(iterable)`|Ждёт первый успешный|`Promise.any(iterator)`|

**Почему это важно:** итератор — это поток значений. Он не навязывает способ хранения. Потребитель сам выбирает структуру данных, которая лучше всего подходит для его задачи. Один и тот же итерируемый объект может быть собран в массив, Set, Map или обработан через `Promise.all` — в зависимости от того, что нужно в конкретном месте.
