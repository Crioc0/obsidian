# Группировка, локальные альтернации и вложенные скобки

Круглые скобки `()` в регулярных выражениях выполняют группировку, позволяя:

1. **Локальные альтернации** — альтернатива работает только внутри группы:

```js
   const regex = /(cat|dog) (barks|jumps)/;    // Ищет: cat или dog, затем пробел, затем barks или jumps
   console.log(regex.test("cat barks")); // true
   console.log(regex.test("dog jumps")); // true
```    
2. **Вложенные скобки** — группы можно вкладывать друг в друга:
```js
   const regex = /((cat|dog) (barks|jumps))/;
  // Внешняя группа: всё выражение
   // Внутренняя группа 1: cat|dog
   // Внутренняя группа 2: barks|jumps
```
