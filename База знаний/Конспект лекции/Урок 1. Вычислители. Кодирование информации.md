Вычислитель делает вычисление над данными(процессор) по определенному набору инструкций. Данные должны быть в понятном для вычислителя формате.

Любая программа - просто последовательной доступных для вычислителя операций.

Любая программа записывается бинарным языком. Часть отвечает за данные, часть за инструкции. Это поток двоичных цифр - бит. Минимальная группа бит, обрабатываемая процессором - байт.

У каждой операции есть свой код - опкод. Разные вычислители имеют разные опкоды. Придумали некоторые стандартные архитектуры, например x86 или ARM.

Размер байта определяется таким образом, чтобы вмещать в себя наиболее часто используемый тип информации.

Любая информация в компьютере исчисляется в байтах. Есть кибибайты - 1024 байт. Погрешность с килобайтами и кибибайтами небольшая.

Кодирование это процесс преобразования из одной формы в другую, декодирование это преобразование информации в исходную форму.

У каждого формата данных свой алгоритм кодирования и декодирования.

Процессоры нативно поддерживают разные виды чисел и операции над ними. Компьютер, как правило, понимает только двоичную систему.

Прямой код -> 1 * 2 ** 1 + 0 * 2 ** 0

Большинство числовых типов имеет ограниченный размер. Используя прямой код, можно закодировать 256 чисел в одном байте.

В отрицательных числах первый бит выделяется для знака, от -127 до 127. Но появляется -0.
Вычитание делается через сложение: 7-9 -> 7 +(-9). 

Чтобы инвертировать знака числа применяется операция побитового отрицания. Такой алгоритм называется обратным кодом, или дополнением до единицы. Все равно есть -0

Дополнительный код(дополнение до двух) - после инвертирования бит делаем +1


Прямой и дополнительный код кодируют только целые числа.

Лишние биты при сложении отбрасываются, так как число ограничивается количество бит, которое оно может занимать. Это называется переполнением.

На одни и те же биты можно смотреть с разными контрактами, например uint8 и int8 будет разная интерпретация результата.

Значения разных типов могут быть по разному представлена в памяти. Процесс преобразования типа в другой называется преобразованием типа, а интерпретация данных одного типа в качестве значения другого называется приведением
