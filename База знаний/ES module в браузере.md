# Zettelcasten Note

Es-модули появились в браузерах в 2017 году. Они помогли изменить парадигму Webpack, так как теперь сам браузер может строить графы зависимостей.  При редактировании файла Vite использует [горячую замену модулей](https://vite.dev/guide/features#hot-module-replacement) (Hot Module Replacement, HMR) вместо нативного ESM, чтобы обновлять только этот модуль в браузере, без полной перезагрузки страницы и ожидания перекомпиляции.

В случае, если использовать ES Module в браузере без сборщиков, обязательно необходимо указывать расширение файла, иначе браузер не поймет, какой файл ему нужно запросить
