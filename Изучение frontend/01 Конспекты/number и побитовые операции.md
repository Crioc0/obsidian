# number и побитовые операции

Побитовые операторы (`&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`) в JavaScript работают особым образом:

1. Операнды преобразуются в 32-битные знаковые целые
2. Выполняется операция
3. Результат преобразуется обратно в 64-битное число

```js
// Обычное сложение
console.log(0b1111111111111111111111111111111 + 1); // 2147483648

// Побитовое сложение (работает в 32-битном пространстве)
console.log(0b1111111111111111111111111111111 | 0); // 2147483647

// Интересный пример
console.log(4294967295 >> 0);   // -1 (из-за преобразования в 32-битный знаковый)
console.log(4294967295 >>> 0);  // 4294967295 (беззнаковый сдвиг)
```

**Последствия:**

- Побитовые операции работают только в диапазоне 32-битных знаковых целых
- Большие числа "обрезаются" до 32 бит
- Это может быть как полезным (битовые флаги), так и неожиданным

### Переполнение при побитовых операциях

При использовании побитовых операторов числа выходят за пределы 32-битного диапазона:

```js
// 2³² - 1 (беззнаковый максимум)
console.log(4294967295 >> 0);   // -1

// Почему -1? Потому что 4294967295 в 32-битном знаковом = 0xFFFFFFFF = -1

// Беззнаковый сдвиг даёт другой результат
console.log(4294967295 >>> 0);  // 4294967295

// Но для чисел больше 2³² - 1
console.log(4294967296 >> 0);   // 0
console.log(4294967296 >>> 0);  // 0
```

Это важный момент при работе с битовыми масками и хешированием в JavaScript.
