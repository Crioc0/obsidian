# Оптимизация SMI (Small Integer)

**SMI (Small Integer)** — это оптимизация, при которой маленькие целые числа не выделяются в куче, а хранятся прямо в указателе на значение.

**Диапазон SMI в V8: 32/31-битные знаковые целые.

Преимущества SMI:

- Нет аллокации памяти
- Нет сборки мусора для этих чисел
- Быстрый доступ и операции

```js
// SMI — маленькое целое
let a = 42;          // хранится в стеке/регистре

// HeapNumber — выходит за пределы SMI или дробное
let b = 1e10;             // Вне диапазона SMI, в куче
let c = 3.14;             // Дробное, в куче
let d = 9007199254740991; // Большое целое, в куче
```
