# Как сделать адаптивный размер шрифта
Чтобы адаптивный размер шрифта, можно задать размер шрифта в **vh**. Чисто этого недостаточно, так как на супер больших и маленьких экранах шрифт будет слишком большим или маленьким. Чтобы избежать этого, нужно использовать функцию CSS clamp. Чтобы осталась возможность изменения размера шрифта при скролле, можно использовать **calc(7vh+1rem)** . В целом, можно избежать использования calc, так как clamp поддерживает вычисления

## Пример 
```css
h1 {
	fontsize: clamp(1.8rem, calc(7vh + 1rem), 5rem)
}

```

```css
h1 {
	fontsize: clamp(1.8rem, 7vh + 1rem, 5rem)
}
```
