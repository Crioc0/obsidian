# Побитовая маска

Можно условно "отбрасывать" лишние биты, чтобы работать только с нужными. Допустим, нужно прочитать биты с 24 по 32 биты в некоторым 32 битном числе. Для того, чтобы это сделать, нужно получить число, где в нужных позициях стоит 1, а в остальных 0. Такое число называется **маской**. Применение маски к исходному числу через побитовое & "отбросит" все лишние биты.

Создать произвольную маску можно с помощью следующей функции
```js
function createMask(position,size) {
	let mask = 1;
	mask = (mask << size) - 1 
	mask =	mask << position
	return mask
}
```
Возьмем за основу 1 (**0b0000000000000001**) и сдвинем все биты этого числа влево на размер нашей маски (в нашем случае это 8) Получиться число **0b0000000100000000** (256) Отнимаем 1 и получается **0b0000000011111111**.(255) Это получается благодаря свойствам позиционной системы. Сдвигая число 1 влево на заданное количество бит мы делаем число на 1 больше нужного нам. Отнимаем 1 и получаем нужное. Далее маску нужно сдвинуть на нужно чилсло
```js
	0b00000000000000000000000011111111 << 24 
== 
	0b11111111000000000000000000000000
```
