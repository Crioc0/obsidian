# Стек вызовов функции

Функции являются самой нагруженной частью программы, а значит из работы должны быть максимально эффективной. Функция не может выполниться частично- она всегда применяется целиком. При этом функции выполняются в порядке последним пришел - первым ушел, следовательно, если внутри функции будет вызов новой функции, то выполнение функции приостановится и запустится внутренняя.

Поэтому для функции использую абстрактную структуру стек, реализованную на обычном массиве. Когда функция вызывается, в стек помещается (push) её память: аргументы, локальные переменные и адрес возврата. Когда функция завершается, её память извлекается из стека (pop). Если функция A вызывает функцию B, стек растёт: после памяти A кладётся B. При возврате из B её память удаляется, возвращая управление A. Благодаря этому последний вызванная функция возвращается первой — принцип LIFO (Last In, First Out).
