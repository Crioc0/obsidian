# Селекторы в CSS

Селекторы в CSS определят, к каким элементам применяются определенные стили c учетом их специфичности. CSS селекторы можно использовать, чтобы выбирать элементы с помощью JavaScript. Комбинаторные селекторы можно использовать для того, чтобы более гибко описывать элементы, к которым нужно применить стили. Также можно использовать псевдоклассы для большего уточнения правил применения
