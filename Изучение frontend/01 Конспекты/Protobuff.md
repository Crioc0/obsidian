# Protobuff

Protobuf — это формат и инструментарий от Google, который требует предварительного описания структуры данных в специальном `.proto` файле. Поддерживает богатый набор встроенных типов, а также механизмы для прямой и обратной совместимостей. За счет схемы очень компактно упаковывает данные (в среднем в 1.3-1.5 раза лучше MessagePack). Скорость парсинга и сериализации зависит от реализации

**Основная идея:** Вместо того чтобы передавать имена полей с каждым объектом (как в JSON), мы один раз договариваемся о схеме, а в данных передаём только номера полей (теги).

**Файл person.proto:**

```proto
syntax = "proto3";

message Person {
  string name = 1;      // тег поля = 1
  int32 age = 2;        // тег поля = 2
  string email = 3;     // тег поля = 3
}
```

**Как работает компиляция:**

1. Вы пишете `.proto` файл.
2. Запускаете компилятор `protoc`, который генерирует код для вашего языка (JavaScript, Python, Go, C++, Java и др.).
3. Сгенерированный код содержит классы для создания и сериализации объектов.
4. Вы используете эти классы в своём приложении.

```shell
# Генерация JavaScript кода
protoc --js_out=import_style=commonjs,binary:. person.proto
```

**Использование сгенерированного кода:**

```js
const protobuf = require("./person_pb");

// Создание объекта (используем сгенерированные методы)
const person = new protobuf.Person();
person.setName("Alice");
person.setAge(30);
person.setEmail("alice@example.com");

// Сериализация
const buffer = person.serializeBinary();
console.log(buffer.length);  // Очень компактно! Около 10-15 байт

// Десериализация
const restored = protobuf.Person.deserializeBinary(buffer);
console.log(restored.getName());  // "Alice"
```

**Почему так компактно?** Protobuf использует технику Varint (variable-length integer), где маленькие числа занимают 1 байт, а большие — больше. Теги полей (1, 2, 3) кодируются вместе с типом данных в одном байте.

**Обратная совместимость — ключевая фишка Protobuf:**

```proto
// Старая версия (v1) — работает на сервере
message Person {
  string name = 1;
  int32 age = 2;
}

// Новая версия (v2) — обновили клиента
message Person {
  string name = 1;
  int32 age = 2;
  string phone = 3;  // новое поле — старый сервер просто его проигнорирует
}
```

Правила совместимости:

- **Можно:** добавлять новые поля с новыми тегами
- **Можно:** удалять поля (но их теги больше нельзя использовать)
- **Нельзя:** менять тег существующего поля
- **Нельзя:** менять тип существующего поля
