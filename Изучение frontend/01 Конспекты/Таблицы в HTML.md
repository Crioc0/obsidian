# Таблицы в HTML


## Что это? (Определение)
Тег **table** представляет табличную дату 

## Зачем это нужно? (Применение)
Для представление данных в двумерном формате, ранее к тому же использовалась для верстки сайтов

## Как это работает? (Принцип)
Структурно можно использовать несколько тегов :
1) **caption** для описания (или названия) таблицы
2) **colgroup** для указания групп столбцов. (должен указываться обязательно перед любыми тегами таблицы кроме **figcaption**). Для указания нужно передать атрибут **span** с числом колонок в группе
3) **thead** для указания строк шапки таблицы (ячеек с заголовками)
4) **th** для указания ячеек в заголовке
