# Таблицы в HTML


## Что это? (Определение)
Тег **table** представляет табличную дату 

## Зачем это нужно? (Применение)
Для представление данных в двумерном формате, ранее к тому же использовалась для верстки сайтов

## Как это работает? (Принцип)
Структурно можно использовать несколько тегов :
1) **caption** для описания (или названия) таблицы
2) **colgroup** для указания групп столбцов. (должен указываться обязательно перед любыми тегами таблицы кроме **figcaption**).  
3) **col** должен находиться внутри **colgroup**  Для указания нужно передать атрибут **span** с числом колонок в группе
4) **thead** для указания строк шапки таблицы (ячеек с заголовками)
5) **th** для указания ячеек-заголовков
6) **tbody** для указания тела таблицы
7) **tr** для указания строки
8) **td** для указания ячейки в теле таблицы
9) **tfoot** для указания 


Атрибут scope нужен для семантики, указывая, к чему относится заголовок.

Для удобства стилизации таблицу можно представить в виде 6 наложенных друг на друга слоев.
Фон, заданный для элемента в одном слое, будет виден только в том случае, если у слоёв над ним прозрачный фон. Пропущенная ячейка отображается так, как если бы это место занимала анонимная ячейка таблицы.

## Пример 
```html
<table>
  <caption>
    Superheros and sidekicks
  </caption>
  <colgroup>
    <col />
    <col span="2" class="batman" />
    <col span="2" class="flash" />
  </colgroup>
  <thead>
    <tr>
      <td></td>
      <th scope="col">Batman</th>
      <th scope="col">Robin</th>
      <th scope="col">The Flash</th>
      <th scope="col">Kid Flash</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Skill</th>
      <td>Smarts, strong</td>
      <td>Dex, acrobat</td>
      <td>Super speed</td>
      <td>Super speed</td>
    </tr>
  </tbody>
</table>
```
