# Императивное программировании


## Что это? (Определение)
Есть изменяемое состояние, и набор императивов, изменяющих это состояние. Если язык сохраняет эту парадигму, его называют императивным.

Свойства императивного языка:
1) Наличие изменяемой памяти
2) Изменение глобального состояния программы
3) Последовательное выполнение инструкций

## Зачем это нужно? (Применение)
Для написания программ

## Как это работает? (Принцип)
Есть набор операций, есть данные, и есть операции, изменяющие эти данные. И язык Assembler, и JS являются императивным
