# Основной синтаксис CSS

Основной синтаксис CSS состоит из пары свойство(идентификатор действия, которое будет применено к элементу) и его значение. Свойств CSS более 100, значений же бесконечное количество. Ключ и значение разделяется двоеточием, регистронезависимы, а пробелы независимы. Если свойство или значение недействительно, CSS-движок это просто игнорирует. 

Наборы ключей и значений заключены в фигурные скобки, объединяясь в блоки, и применяются к к одному или нескольким селекторам, разделенных запятыми - это условия, определяющие некоторые элементы страницы. Такой набор называется набором правил, или правилом. Стили применяются согласно каскадному алгоритму. 

Помимо объявления правил, можно использовать At-правила, начинающиеся с @, как правило для метаданных, условной информации(@media,@document) или описательной информации(@font-face)

Условия могут быть вложенными, например, применяться только к элементам на определенной ширине экрана(@media)
