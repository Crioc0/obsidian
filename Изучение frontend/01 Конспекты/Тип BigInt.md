# Тип BigInt
Особенность bigint состоит в том, что занимаемая типом память может меняться динамически в зависимости от конкретного значения, что позволяет хранить действительно большие числа без страха числового переполнения. Фактически, значение в bigint ограничено лишь доступной памятью виртуальной машины.

Нельзя применять арифметические операции между bigint и number без явного преобразования типов. При преобразовании типов может быть отброшена дробная часть или случиться переполнение. Также, в отличии от number, применение побитовых операций не делают преобразование к Int32/Uint32

`bigint` медленнее для маленьких чисел, чем number, но для больших чисел, выходящих за безопасный диапазон, он является единственным способом сохранить точность.


**Особенности:**

- Целые числа любой длины
- Нет потери точности
- Нельзя смешивать с number без явного преобразования
- Поддерживает `+`, `-`, `*`, `**`, `/`, `%`, сравнения
- Побитовые операции работают (с приведением к бесконечной длине)

### Области применения bigint

- **Криптография** — работа с большими простыми числами
- **Идентификаторы** — когда ID могут быть больше 2⁵³ (Twitter IDs, Snowflake IDs)
- **Таймстемпы** — наносекундные временные метки
- **Большие счётчики** — счётчики просмотров, лайков у больших систем
- **Интероперабельность** — с серверными API, возвращающими большие целые
