# Системы счисления
Система счисления определяет алфавит цифр из которых строятся числа В 10-тиричной системе счисления 10 цифр (от 0 до 9) В 2-ичной системе 2 цифры (0 и 1) В 16-тиричной системе 16 цифр (от 0 до 9, а потом от A до F)

```js
console.log((1255).toString(2)); // 10011100111
console.log((1255).toString(8)); // 2347 
console.log((1255).toString(10)); // 1255 
console.log((1255).toString(16)); // 4e7 
console.log((1255).toString(36)); // yv
```

```js
// Отладчик JS выводит числа в 10-тиричной системе 
console.log(parseInt("10", 2)); // 2 
console.log(parseInt("10", 8)); // 8 
console.log(parseInt("10", 16)); // 16 
console.log(parseInt("10", 36)); // 36
```
ВИЗУАЛЬНО РАЗНЫЕ ЧИСЛА МОГУТ БЫТЬ ОДИНАКОВЫМИ
```js
console.log(0b1111_1111 === 255); // true 
console.log(0xFF === 255); // true 
console.log(0xFF === 0o377); // true
```

Система счисления позволяет записать и прочитать число Число «двести пятьдесят пять» может быть записано как: 255, FF или 1111 1111 Но оно все равно остается «двести пятьдесят пять»
