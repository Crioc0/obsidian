# Исчисления


## Что это? (Определение)
Исчисления описывают "алфавит" и синтаксис языка домена, набор базовых аксиом(истины), набор правил вывода(как одно выводится из другого). Используя это, выводятся теоремы и леммы. Для доказательства используется индукция.

## Зачем это нужно? (Применение)
Для вычислений

## Как это работает? (Принцип)
Исчисления пишутся в виде последовательно описанных правил.
