# Двусторонняя очередь (дек)

Двусторонняя очередь (Deque - Double Ended Queue) позволяет добавлять и извлекать элементы с обоих концов последовательности

**Операции:**

- `pushBack` / `pushFront` — добавление в конец / начало
- `popBack` / `popFront` — удаление с конца / начала
