# Протокол TCP IP

Двумя самыми важными протоколами являются протокол управления передачей данных (Transmission Control Protocol, TCP) и протокол интернета (Internet Protocol, IP). Совокупность этих протоколов называют TCP/IP. За развитие интернет стандартов отвечают IETF, Internet Engineering Task Force. Документы стандартов называются RFC, request for comments
