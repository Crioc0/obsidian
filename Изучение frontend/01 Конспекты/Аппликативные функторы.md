# Аппликативные функторы


## Что это? (Определение)

Если интерфейс функтора позволяет вызывать функции на контейнере, то интерфейс аппликативного функтора позволяет работать с функциями в контексте контейнера
## Зачем это нужно? (Применение)

Сигнатура map у функтора предполагает, что её фунарг принимает только один аргумент А ap позволяет выполнять функции с большим количеством аргументов Например, 
```js
Option.Some(42).map((a, b) => a + b).ap(10);
```
 и «учитывать контекст» каждого аргумента Например,
 ```js
  findAge("Боб").map((a, b) => a + b).ap(findAge("Джен"));
 ```
