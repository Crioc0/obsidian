# Типы данных
Процессо не понимает смысла того, что делает. У него есть ограниченный набор операций, и программист сам должен решать, что и с чем использовать. Чтобы облегчить себе жизнь, были придуманы типы данных.

По сути, тип - это некоторое мнемоническое имя, которое определяет множество данных закодированных определенным образом, а также набор контрактов и поддерживаемых операций.

Значения разных типов могут по разному быть представлены в памяти. Процесс конвертации из одного типа в другой называется преобразованием типа. Интепретация представления данных одного типа в другой называется приведением типов.
