# Представление данных в текстовом и бинарном форматах

### Текстовое представление данных

В действительности, никакого текста в компьютере нет - только поток байт

Тестовое представление данных это способ записи информации в виде последовательности символов, понятного человеку. Любой текст по сути своей - это набор чисел, где каждому символу соответствует свой код в кодировке (ASCII, UTF-8 и т.д)

### Бинарное представление данных

Это способ записи информации так, как компьютер хранит её в памяти: числа занимают ровно столько байт, сколько нужно для их типа (4 байта для 32-битного целого, 8 байт для 64-битного числа с плавающей точкой и т.д.).
