# Виды вычислительный контейнеров


## Что это? (Определение)
Есть много видов вычислительных контейнеров, таких как 
1) [[Контейнер Option]] - данных может не быть
2) [[Контейнер Result]] - данных может не быть из-за ошибки(как Promise, только без Pending)
3) [[Контейнер Lazy]] - абстракция для цепочки ленивых вычислений
4) Mutex или RWLock - защита разделяемого состояния
5) Writer - логирование операций над данными
6) [[Контейнер Promise в ФП]] 
Примеры контейнеров ограничены только воображением
