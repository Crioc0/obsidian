# Каррирование


## Что это? (Определение)
Представление функций  со множеством аргументов называется каррированием. Функция, которая поддерживает такую работу, называется каррированной. 

## Зачем это нужно? (Применение)
Для упрощения применения частично примененных функций, чтобы не вызывать явно call
## Как это работает? (Принцип)
Каррирование создает функцию высшего порядка, которая возвращает новую функцию

## Пример 
```js
function curry(fn) {
	return (...args) => {
		if(fn.length> arg.length){
			return curry(fn.bind(nul,...args));
		}
		
		return fn(...args)
	}
}

const sum = curry((a,b,c)=>a+b+c);
const add42 = sum(10,32)

console.log(add42(10)) // 52
```
