# Кэш-линии

Размер кэша значительно меньше возможного размера DRAM. Из-за этого приходится постоянно загружать и выгружать данные из кэша. Этой логикой занимается контроллер кэша. Помимо самих данных из DRAM, в кэше нужно хранить их адреса. Чтобы не хранить адрес каждого каждого байта, их объединяют в группы - кэш-линии. Тогда нужно будет хранить только адрес кэш-линии. Размер линии на x86 равен 64 байтам.

Если данные решат рядом в памяти, то они с высокой долей вероятности будут лежать рядом и в кэше. Когда мы обходим массив последовательно, получается минимизировать обращение к DRAM за счет использования кэша
