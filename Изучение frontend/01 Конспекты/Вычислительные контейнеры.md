# Вычислительные контейнеры

## Пример 

Любое значение программы можно наделить некоторым контекстом. Контекст может добавлять "состояние" данных  или некоторый "эффект". В один момент времени контейнер может находится только в одном состоянии. 

## Зачем это нужно? (Применение)
Для инкапсуляции данных, благодаря контейнерам можно строить "цепочки вычислений" в контексте.
Вместо написания кучи if/else можно написать [[Виды вычислительный контейнеров | множество универсальных контейнеров]] и работать с ними


## Как это работает? (Принцип)
Яркий пример контейнера в JS это Promise. Этот контейнер добавляет данным одно из трех состояний: Rejected, Fullfilled или Pending. Promise инкапсулирует доступ к данным, доступ к сырым данным закрыт API контейнера

## Пример 
```js
Promise.resolve(0)
.then(v => 42 / v) 
.then(v => { if (isFinite(v)) return v; else throw "Не число" })
.then(v => v * 10) 
.then(console.log) 
.catch(console.error)
```
