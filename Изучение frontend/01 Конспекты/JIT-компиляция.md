# JIT-компиляция

JIT-компиляция работает параллельно с исполнением нашей программы. Программа может стартовать через интерпретатор. Часто вызываемые фрагменты или функции постепенно компилируются в машинные коды. Со временем программ начинает работать быстрее.

Есть техника прогрева - можно прогреть некоторые часто используемые функции, чтобы она быстрее сработала, част используется на сервере, на фронте лучше не использовать

![[Разница между AOT и JIT.png]]

В JS не каждая фнкцию может скомпилирована JIT, например, функции с EVAL никогда не будет оптимизирован. Здесь работает правило: чем строже код, тем больше шансов на успех. В JS функции могут принимать разные типы аргументов – JIT будет вынужден создавать отдельные функции для разных типов.

Наличие или отсутствие JIT компилятора никак не регламентируется в спецификации JavaScript, даже наличие байткода и его формат. Реализаций JavaScript существует очень много: V8, SpiderMonkey, JavaScriptCore. Минималистичные реализации: QuickJS, JerryScript. Они следуют спецификации ECMAScript, но нюансы реализации у всех свои.
