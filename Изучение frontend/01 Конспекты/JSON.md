# JSON

JSON — это текстовый формат обмена данными, основанный на синтаксисе JavaScript. Он стал стандартом в веб-разработке благодаря своей простоте и естественной поддержке в браузерах.

**Поддерживаемые типы данных:**

- Строки (в двойных кавычках)
- Числа (целые и с плавающей точкой)
- Логические значения (true, false)
- null
- Объекты (неупорядоченные коллекции пар "ключ-значение")
- Массивы (упорядоченные списки значений)

**Что отсутствует в JSON:**

- Комментарии (их нет по спецификации)
- Висячие запятые (запятая после последнего элемента — синтаксическая ошибка)
- Ссылки на другие части документа
- Дата и время как отдельный тип

**JSON5** — это надстройка над JSON, которая добавляет:

- Комментарии (// и /* */)
- Ключи без кавычек
- Висячие запятые
- Однострочные строки в одинарных кавычках

```js
{
// это комментарий
    name: "Alice",  // ключ без кавычек, значение в одинарных кавычках
        age
:
    30,
        hobbies
:
    ["coding", "reading"],  // висячая запятая не вызывает ошибку
}
```
