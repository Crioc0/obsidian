# Компиляция и компилятор

Можно создать программу, которая будет принимать исходный код и транслировать его в машинный код под конкретную платформу

**Компилятор** — это программа, которая переводит исходный код (на языке высокого уровня) в машинный код (или другой целевой формат) до начала выполнения.

**Этапы компиляции:**

1. Лексический анализ (разбор на токены)
2. Синтаксический анализ (построение AST)
3. Семантический анализ (проверка типов и т.д.)
4. Генерация промежуточного кода (байткод, IR)
5. Оптимизация
6. Генерация машинного кода

Помимо трансляции, компилятор проверяет ошибки в исходном коде и делать различные оптимизации, чтобы конечный код работал эффективнее. 

По этой причине компилируемые языки часто отличаются более высокой производительностью исполнения конечного кода 

Компиляцию нужно производить под каждую отдельно взятую архитектуру

**Явная фаза компиляции:** в языках типа C, C++, Rust, Go компиляция происходит до запуска программы. Получается исполняемый файл, который можно распространять и запускать без исходников. Сам компилятор не запускает программу
