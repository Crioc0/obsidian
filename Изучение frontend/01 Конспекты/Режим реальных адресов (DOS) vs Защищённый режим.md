# Режим реальных адресов (DOS) vs Защищённый режим

Раньше процессоры работали в режиме реальных адресов — это такой режим, в котором не было виртуальной памяти. Логические адреса однозначно отображались на физические. Например, в этом режиме работал DOS. При таком подходе не было многозадачности в современном понимании, а программисты могли руками управлять памятью.

Современные процессоры работают в защищённом режиме (хотя режим реальных адресов оставлен для совместимости). Программы в таком режиме работают с памятью, используя API операционной системы (например, аллокатор). Это именно тот подход, который сейчас используется в низкоуровневом программировании. Даже программы на языках ассемблера сейчас в основном работают через API ОС.
