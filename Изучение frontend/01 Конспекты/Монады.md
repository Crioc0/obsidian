# Монады


## Что это? (Определение)
Если контейнер поддерживает интерфейс такого типа, то он называется монадой
```js
flatMap(fn) { return this.isNone() ? this : fn(this.#value); }
```

## Зачем это нужно? (Применение)
[[Функторы| Функторный]] метод никак не анализирует то, что вернул его фунарг, и в результате может появиться вложенный тип. Например
```js
Option.Some("42").map(parse) // Some(Some(42))
Option.Some("42").flatMap(parse) // Some(42)
```

## Как это работает? (Принцип)
Разберем монаду на примере flatMap(fn)
Функция fn ожидает чистое значение, но возвращает контейнер.(тип возвращаемого контейнера совпадает с исходным контейнером). Результатом работы всей функции является полученный контейнер
