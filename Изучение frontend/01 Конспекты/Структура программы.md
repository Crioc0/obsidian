# Структура программы

По сути своей программа состоит из следующих компонентов:
1) Код (функции, процедуры, классы, методы)
2) Локальные данные (аргументы и локальные переменные, временные объекты)
3) Глобальные данные (глобальные переменные и константы)
4) Статистические данные (литералы, временные объекты)
5) Внешние динамические библиотеки (разделяемые библиотеки, плагины, нативные модули)
