# Динамические цвета
Благодаря функции **hsl()** можно получить динамические цвета из **::root** переменных. **hsl** это функциональная нотация, описывающая цвет с помощью трех параметров: (hue: оттенок, saturation: насыщенность, lightness: светлость). 
Можно получить свет с помощью ключевого слова from с его параметрами и применить функцию calc к необходимым свойствам
```css
::root {
--main-color: blue
}

.button{
bg-color: hsl(from var(--main-color) h s calc(l-10) / 0.5)
}
```
Управлять прозрачностью можно с помощью записи через слэш
