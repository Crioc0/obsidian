# Язык ассемблера

Ассемблер — это "человекочитаемая" обёртка над машинным кодом. Вместо `B8` пишется `mov eax, 1`. Каждая инструкция ассемблера соответствует одной машинной инструкции.

```
mov eax, 1
add eax, 2
cmp eax, 3
jz label
```

Ассемблер привязан к архитектуре: x86-ассемблер не подойдёт для ARM. Но он даёт полный контроль над процессором и позволяет писать очень эффективный код.

**Плюсы ассемблера:**

- Максимальная производительность (можно использовать все возможности процессора)
- Полный контроль над памятью и регистрами
- Возможность писать код для железа без операционной системы (микроконтроллеры, загрузчики, ядра ОС)

**Минусы ассемблера:**

- Низкая скорость разработки
- Высокий порог входа
- Код непереносим между архитектурами
- Сложность поддержки и отладки
