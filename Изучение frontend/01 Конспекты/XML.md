# XML

XML — это текстовый формат для хранения структурированных данных, основанный на тегах (как HTML). Он был очень популярен в 2000-х годах, но в вебе его постепенно вытеснил JSON. По сути своей метаязык для создания языков разметки Многие языки разметки явно или косвенны сделаны на основе XML: HTML, SVG (векторная графика), MathML (математические формулы). XML не самостоятельный язык разметки данных, а набор синтаксических правил для создания таких языков

**Структура XML:**

- Пролог (декларация XML)
- Корневой элемент (обязательно один)
- Открывающие и закрывающие теги
- Атрибуты (дополнительная информация в тегах)
- Текстовое содержимое

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!-- Комментарии — можно и нужно -->
<person id="123">  <!-- атрибут id -->
    <name>Alice</name>
    <age>30</age>
    <address>
        <city>Moscow</city>
        <street>Lenina</street>
    </address>
</person>
```

**Сильные стороны XML:**

1. **Валидация через схемы (XSD, DTD)** — можно описать строгую структуру документа (какие элементы обязательны, какие атрибуты допустимы, какие типы данных используются). Это незаменимо в сложных корпоративных интеграциях.
2. **Пространства имён (namespaces)** — возможность смешивать данные из разных словарей в одном документе (например, XHTML + MathML + SVG).
3. **XPath и XSLT** — мощные языки для запросов к XML-документам и их трансформации.
4. Очень хорошая поддержка различными ПО.

**Слабые стороны XML:**

1. **Огромная избыточность** — для передачи той же информации, что в JSON, XML часто требует в 2-3 раза больше байт.
2. **Сложный парсинг** — XML-парсеры обычно строят DOM-дерево, что потребляет много памяти.
3. **Сложность ручного редактирования** — легко пропустить закрывающий тег.

**Парсинг XML в браузере:**

```js
const parser = new DOMParser();
const xmlString = `
  <people>
    <person id="1">Alice</person>
    <person id="2">Bob</person>
  </people>
`;
const xmlDoc = parser.parseFromString(xmlString, "text/xml");

// Проверяем ошибки парсинга
const parserError = xmlDoc.querySelector("parsererror");
if (parserError) {
    console.error("Ошибка парсинга XML");
}

// Чтение данных
const persons = xmlDoc.querySelectorAll("person");
persons.forEach(person => {
    console.log(person.textContent);     // Alice, Bob
    console.log(person.getAttribute("id"));  // 1, 2
});
```
