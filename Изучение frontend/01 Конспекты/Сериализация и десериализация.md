# Сериализация и десериализация

Логически похожа на маршалинг и демаршалинг, но с той разницей, что сохраняется не все состояние, а только данные. Выбранный формат для сериализации может просто не поддерживать все возможные типы данных нашего ЯП. Например, в JSON нет отдельного формата для дат – даты нужно кодировать либо как строки, либо как числа.
