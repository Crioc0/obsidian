# Почему 0.1 + 0.2  !== 0.3

о самый известный "подводный камень" всех языков с IEEE 754. Причина — двоичное представление десятичных дробей.

```js
console.log(0.1 + 0.2);                     // 0.30000000000000004
console.log((0.1 + 0.2).toFixed(20));       // 0.30000000000000004441

// Проверка с эпсилоном
const epsilon = 1e-10;
console.log(Math.abs(0.1 + 0.2 - 0.3) < epsilon); // true
```

**Почему это важно:**

- В финансовых приложениях такая ошибка недопустима
- В научных расчётах может накапливаться
- При сравнении дробных чисел нужно использовать эпсилон, а не ===
