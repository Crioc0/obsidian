# Побитовое НЕ

- Дает 1, если значение 0 и 0 – если 1
- ~0 == 1 | ~1 == 0 
- Можно сменить знак числа, например, ~42 + 1 == -42 
- Иногда используют с методами, которые возвращают -1, ведь ~-1 == 0 Например, if (~[1, 2, 3].indexOf(10)) { console.log("Не найдено!"); } Применение ~0 даст число из одних единиц (-1 или 4294967295)
