# Списки HTML


## Что это? (Определение)
Если три типа списков : упорядоченный, нумерованный и список описаний 

## Зачем это нужно? (Применение)
Для упорядочивания информации. Списки при необходимости можно вкладывать друг в друга

## Как это работает? (Принцип)
Для создания нумерованного списка используется тег **ul** для нумерованного **ol**. Для элемента списка используется тег **li** 

Для создания списка описаний используется тег **dl**. Для термина используется тег **dt**, для описания **dd**
