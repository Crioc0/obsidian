# Логический сдвиг вправо (логический оператор)

Все биты числа сдвигаются на заданное количество бит вправо Слева «дозаписываются» нули (число всегда становится положительным) **-1 >>> 0 == 4294967295** Для положительных чисел эффект такой же, как и при **>>**. Он позволяет просто сдвинуть биты «как есть» без логики знака.

Когда мы просто читаем значение по некоторой маске, то можно не двигать маску на нужную позицию, а сдвинуть само значение Именно это мы тут и делам **(bcd >>> 4) &** **0b1111**
