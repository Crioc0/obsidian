# Контейнер Lazy


## Что это? (Определение)
Контейнер Lazy нужен для ленивых вычислений.
Ленивыми называются вычисление, которые делаются не сразу, а по явному требованию. Например, пока пользователь не нажмет на кнопку или не включит специальную настройку

## Пример 
```js
const readConfig = new Lazy(initConfig).then(applyConfig); console.log(readConfig.call()); // Функция выполниться только теперь console.log(readConfig.call()); // Повторный вызов делаться не будет - сразу вернется результат console.log(readConfig.call());
```
