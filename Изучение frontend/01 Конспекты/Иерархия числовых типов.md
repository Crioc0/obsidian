# Иерархия числовых типов

![[Иерархия числовых типов.png]]
Числовые типы в программировании можно представить в виде иерархии:

- **Целые числа (integers)** — без дробной части: делятся на знаковые и беззнаковые.
- **Дробные числа** — с плавающей точкой (float), с фиксированной точкой (fixed-point) или рациональные дроби.
- **Комплексные числа** — специальный тип для научных вычислений.

C математической точки зрения существует много большее количество числовых типов.

При этом с точки зрения кодирования числа можно разделить на двоичные и десятично-двоичные (специальные типы, где важна точность десятичного представления).

![[Типы чисел для процесора.png]]

Аппаратная поддержка операций значительно ускоряет работу с ними.

В разных языках эта иерархия реализована по-разному. В C/C++ есть отдельные типы для целых разной разрядности (`int8_t`, `int16_t`, `int32_t`, `int64_t`) и для чисел с плавающей точкой (`float`, `double`). В JavaScript же с числами всё сложнее — там есть тип `number` (который пытается быть всем) и `bigint`.

При работе с числами в программировании важно понимать несколько ключевых моментов:

1. **Разрядность** — сколько бит отведено под хранение числа. Чем больше бит, тем шире диапазон и выше точность, но тем больше памяти потребляется.
    
2. **Знаковость** — есть ли поддержка отрицательных чисел. Знаковые типы теряют один бит на хранение знака, сужая диапазон положительных чисел.
    
3. **Точность** — целые числа представляются точно до определённого предела. Дробные числа в двоичной системе часто представляются приближённо.
    
4. **Переполнение** — выход за границы допустимого диапазона. В разных языках обрабатывается по-разному: где-то тихо отбрасывает старшие биты, где-то выбрасывает исключение.
