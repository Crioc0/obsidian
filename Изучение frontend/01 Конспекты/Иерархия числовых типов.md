# Иерархия числовых типов

Числовые типы в программировании можно представить в виде иерархии:

- **Целые числа (integers)** — без дробной части: делятся на знаковые и беззнаковые.
- **Дробные числа** — с плавающей точкой (float), с фиксированной точкой (fixed-point) или рациональные дроби.
- **Комплексные числа** — специальный тип для научных вычислений.

При этом с точки зрения кодирования числа можно разделить на двоичные и десятично-двоичные (специальные типы, где важна точность десятичного представления).

В разных языках эта иерархия реализована по-разному. В C/C++ есть отдельные типы для целых разной разрядности (`int8_t`, `int16_t`, `int32_t`, `int64_t`) и для чисел с плавающей точкой (`float`, `double`). В JavaScript же с числами всё сложнее — там есть тип `number` (который пытается быть всем) и `bigint`.
