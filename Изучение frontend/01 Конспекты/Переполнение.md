# Переполнение

Если в результате сложения двоичных чисел получается число, которое занимает больше бит, чем число может занимать, лишние биты отбрасываются. Это называется переполнением. Именно поэтому числовые типы имеют фиксированный размер. Благодаря переполнению можно делать вычитание при помощи сложения
```js
	01010 
+ 
	10110
	 = 
(1) 00000 

1 + 1 приводит к 0 и переносу 1 в следующий разряд
```

Иллюстрация переполнения
```js
const a = new Uint8Array([255]); 
a[0] += 2; 
console.log(a[0]);  // 1 
					// 1111 1111 
					// + 
					// 0000 0010 
					// = 
					// (1) 0000 0001
```
