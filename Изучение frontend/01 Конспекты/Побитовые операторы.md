# Побитовые операторы

С помощью побитовых операторов возможно работать с байтами напрямую. По сути своей, любое "сложное вычисление" строится из комбинации побитовых операторов. Это самые быстрые операции для процессора. 

Пример: узнаем знак числа
```js
function isNegative(num) { 
	return (num & (1 << 31)) !== 0; 
} 
console.log(isNegative(42)); // false 
console.log(isNegative(-42)); // true
```
