# Структуры

Структуры - одна из важнейших фундаментальных структур данных в программировании.

По сути, описывается схема данных. Используя эту схему данных, можно как кодировать, так и декодировать данных. Закодированные данные лежат рядом в памяти, что благоприятно сказывается на кэшировании. Общий размер структуры равен сумме всех ее полей.

![[Пример представления структуры.png]]

В отличие от массива, у нас появляется возможность хранить в памяти элементы с разным размером или типом Размер структуры известен заранее, поэтому можно сделать массив таких структур Как и сделать другую структуру/массив полем структуры Данные в памяти будут лежать «рядом»

```rust
fn main() { 
	struct User { 
	age: u8, 
	name: String 
	} 
	// У нас на руках адрес первого байта структуры, 
	// поэтому доступ к name можно высчитать статически 
	let bob = User { age: 20, name: "Bob".to_string() }; 
	println!("Hello, {}!", bob.name); }
```
