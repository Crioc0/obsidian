# Интерпретация и интерпретаторы

**Интерпретатор** — это программа, которая читает исходный код и выполняет его построчно, без предварительной компиляции в машинный код.

**Плюсы интерпретации:**

- Не нужно ждать компиляции (быстрый старт)
- Легче писать REPL (Read-Eval-Print Loop)
- Проще переносимость (нужен только интерпретатор)
- Можно выполнять код, который генерируется на лету (eval)

**Пример интерпретатора на JavaScript:**

```js
function interpret(program) {
	const lines = program.split('\n');
	for (const line of lines) {
		if (line.startsWith('print')) {
			const message = line.slice(6);
			console.log(message);
		}
// ... другие команды
	}
}
```

**Минусы интерпретации:**

- Медленнее, чем скомпилированный код
- Каждый раз при запуске нужно разбирать исходный код
- Ошибки типов проявляются только во время выполнения
