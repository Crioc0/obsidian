# Тегированные указатели и перечисление

Массивы накладывают на нас архитектурное ограничение, что размер элемента каждого массива должен быть заранее зафиксирован. Получается, что мы не можем хранить разные типы элементов в одном массиве. Но JavaScript успешно обходит это ограничение за счет использования указателей. В добавок, в самом указателе «хранится признак», о том, что это за указатель. То есть по значению отдельных бит мы можем понять, что это за тип. Такие указатели называются тегированные.

Можно сделать структуру, в которой отдельное поле хранит признак поля-структуры. Такое поле называют дискриминатор, или дискриминант. Тогда можно выделить размер структуры под все нужные нам типы данных и хранить признак, что за тип лежит в конкретной структуре. Как результат, можно хранить разные типы данных в раках одной структуры в одном массиве или поле другой структуры. Такая структура называется перечислением или размеченным объединением.

```rust
fn main() { 
	// Определяем перечисление для цветов 
	enum Color {
		 RGB(u8, u8, u8), 
		 RGBA(u8, u8, u8, u8), 
	} 
	fn main() { 
		let colors = [ 
			Color::RGB(255, 0, 0), // Красный 
			Color::RGBA(0, 255, 0, 128), // Зеленый с прозрачностью 
		]; 
		for color in colors.iter() { 
		// Конструкция match позволяет подставить ветку-вычисления согласно дискриминатору 
		match color { 
			Color::RGB(r, g, b) => { 
				println!("RGB цвет: R={}, G={}, B={}", r, g, b); 
			} 
			
			Color::RGBA(r, g, b, a) => { 
				println!("RGBA цвет: R={}, G={}, B={}, A={}", r, g, b, a); 
			} 
		} 
	} 
}
```
