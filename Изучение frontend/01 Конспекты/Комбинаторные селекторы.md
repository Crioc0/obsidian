# Комбинаторные селекторы

## Комбинаторный селектор +(комбинатор следующего элемента)
Применяется в том случае, если один элемент идет следом за другим, и оба элемента являются дочерним для одного и того же родительского элемента
```css
/* Применится к параграфу, который идет сразу за картинкой */ 
img + p { 
	font-weight: bold; 
}
```
Можно скомбинировать с псевдоклассом `:has` для выбора предыдущего родственника
```css
/* Применится к предпосдледнему элементу списка */ 
li:has(+ li:last-of-type) {
	color: red; 
	font-weight: bold;
}
```
## Комбинаторный селектор > (дочерний элемент)
Применится к элементам, соответствующим второму селектору и являющемуся непосредственным потомком первого
```css
ul.my-things > li {
	color: red
}
```
## Комбинаторный селектор ~ (последующий элемент)
Применится ко всем элементам, следующим за первым, и имеют общего непосредственного родителя
```css
/* Применится ко всем абзацам, идущим за картинкой */
img ~ p {
	color: red	
}
```
## Комбинаторный селектор " " (потомок)
Применится ко всем элементам, соответствующим второму селектору и являющимся непосредственным потомком первого
```css
/* Применится ко всем li, являющимися потомком ul.my-list */
ul.my-list li {
	margin: 2em;
}
```
## Комбинаторный селектор | (пространство имен)
Применится ко всем элементам, входящим в пространство имен
```css
/* Links in the namespace named myNameSpace */
myNameSpace|a {
  font-weight: bold;
}
/* paragraphs in any namespace (including no namespace) */
*|p {
  color: darkblue;
}
/* heading level 2 not in a namespace */
|h2 {
  margin-bottom: 0;
}
```
## Комбинаторный селектор , 
Применится ко всем элементам, соответствующим хотя бы одному из этих селекторов
```css
span {
  border: red 2px solid;
}
div {
  border: red 2px solid;
}

span,
div {
  border: red 2px solid;
}
```
Можно удобно сочетать с другими комбинаторными селекторами 
```css
h2:has(+ p, + ul.red) {
  font-style: italic;
}
```
