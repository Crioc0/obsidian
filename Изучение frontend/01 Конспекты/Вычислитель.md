# Вычислитель

Устройство, которое физически может использоваться для вычисления каких-то введенных данных, либо программа, предоставляющее виртуальное устройство

Вычислитель имеет базовый набор команд. По сути вычислитель это просто последовательность операций из набора команд, а вычисление это чтение и выполнение в указанном порядке. Все вычислители по сути отражают реальный мир.

Вычислитель поддерживает фиксированный набор операций. У каждой операции есть свой код (опкод). У разных вычислителей могут быть разные опкоды даже для одних и тех же операций.

Чтобы улучшить переносимость, придумали стандартные архитектуры, например x86 или ARM
