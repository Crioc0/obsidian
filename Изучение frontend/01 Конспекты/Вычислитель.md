# Вычислитель

## Что это? (Определение)
Устройство, которое физически может использоваться для вычисления каких-то введенных данных. 

## Зачем это нужно? (Применение)
Для вычислений

## Как это работает? (Принцип)
Вычислитель имеет базовый набор команд. По сути вычислитель это просто последовательность операций из набора команд, а вычисление это чтение и выполнение в указанном порядке. Все вычислители по сути отражают реальный мир.
