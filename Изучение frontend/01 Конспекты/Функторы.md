# Функторы


## Что это? (Определение)
Если контейнер поддерживает интерфейс такого типа, то он называется функтором. Функторы ничего не знают о контейнере
```js
map(fn) { return this.isNone() ? this : Option.Some(fn(this.#value)); }
```

## Зачем это нужно? (Применение)
Обычные функции не умеют работать с контейнерами, например такой пример не сработает
```js
const plus42 = (a) => a + 42; plus42(Option.Some(10));
```
Вместо создания функции plusOption42 в императивном подходе, можно написать 
```js
Option.Some(10).map(plus42)
```
Интерфейс функтора универсальный, его могут реализовать многие контейнеры.

Массивы в JS это функторы, так как
- Массив – является контейнером для множества элементов 
- Каждому элементу соответствует свой индекс 
- map массива распаковывает каждый элемент и передает функции из аргумента 
- Результат обратно упаковывается в контейнер и мы получаем другой массив 
- Если массив пустой, то и функция не вызовется ни разу

## Как это работает? (Принцип)
В качестве примера можно представить метод map(fn).
Во первых, это функция высшего порядка(функция, принимающая функции).
Во-вторых , функция fn ничего не знает о контексте, в котором запускается. Функция принимает и возвращает чистое значение, а распаковка и упаковка данных происходит внутри самой функции map
