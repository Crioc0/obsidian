# Каррирование с пропуском аргумента


## Что это? (Определение)
Каррированные функции требуют определенный порядок аргументов. Можно пропустить аргумент, передав в функцию аргумент типа **__** 

## Зачем это нужно? (Применение)
Это позволяет более гибко управлять порядком аргументов благодаря пропускам, есть возможность работать с функциями произвольной длины

К минусам стоит отнести дороговизну этой функции - использовать нужно только там, где нужно

## Как это работает? (Принцип)
Аргумент типа **__** игнорируется, то есть аргумент как будто будет передан, и можно передать следующий за ним. Результатом будет функция, в котором нужные аргументы на месте.
Например, эта функция вернет функцию, ожидающую первый аргумент
```js
hasOwn(_,"json)"
```

## Пример 
```js
const _ = {}

function curry(fn) {
	function curried(..args) {
		const placeholders = arg.filter(el=>el===_).length;
		
		if (arg.length>=fn.length && placeholder ===0) {
			return fn(...args)
		}
	
		function inner(...nextArgs) {
		let next =0;
		const combinedArgs = args.map((arg)=>arg===_&& next < nextArgs.length ? nextArgs.length ? nextArgs[next++]:arg)
		
		return curried(...combinedArgs);
		}	
		Object.defineProperty(inner, "length", {value:fn.length - args.length + placeholders})
		return inner
	}
	
	Object.defineProperty(curried, "length", {value:fn.length})
}
```
