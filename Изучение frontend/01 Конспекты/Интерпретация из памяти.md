# Интерпретация из памяти
Если наше число не может иметь знак, то в 8-ми битах мы можем хранить значение от 0 до 255 (256 значение) А если может – от -128 до 127 (тоже 256 значений) Мы можем посмотреть на одни и те же биты как на число со знаком или без

```js
const a = new Int8Array([-125]); 
const b = new Uint8Array(a.buffer); 

console.log(a[0]); // -125 
console.log(b[0]); // 131
```
