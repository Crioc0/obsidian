# Типизация

|Тип типизации|Описание|Примеры языков|
|---|---|---|
|**Статическая**|Типы известны на этапе компиляции|C, Java, Rust, TypeScript|
|**Динамическая**|Типы проверяются во время выполнения|Python, JavaScript, Ruby|
|**Сильная**|Нельзя смешивать типы без явного преобразования|Python, Rust, Java|
|**Слабая**|Типы автоматически приводятся|JavaScript, C (в некоторых случаях)|
|**Явная**|Типы нужно указывать в коде|C, Java, Rust|
|**Неявная**|Типы выводятся компилятором|Haskell, TypeScript (частично)|
|**Утиная (duck typing)**|"Если выглядит как утка и крякает как утка — это утка"|Python, JavaScript, Go (interface{})|
|**Структурная**|Тип совместим, если структура совпадает|TypeScript, Go (interface{})|
### Что даёт типизация

**Статическая типизация:**

- Ошибки типов ловятся на этапе компиляции
- Лучшая производительность (компилятор может оптимизировать)
- Лучшая поддержка IDE (автодополнение, рефакторинг)
- Самодокументируемый код

**Динамическая типизация:**

- Быстрое прототипирование
- Меньше кода (не нужно писать типы)
- Гибкость (можно легко менять типы)

### Эффективность статической типизации

[](https://gist.github.com/kobezzza/f3598aacd9f95d7ee84182b9e3ea5625#%D1%8D%D1%84%D1%84%D0%B5%D0%BA%D1%82%D0%B8%D0%B2%D0%BD%D0%BE%D1%81%D1%82%D1%8C-%D1%81%D1%82%D0%B0%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B9-%D1%82%D0%B8%D0%BF%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D0%B8)

Компилятор, зная тип переменной, может:

- Выбрать оптимальные инструкции (для чисел, для строк)
- Выделить ровно столько памяти, сколько нужно
- Встроить (inline) функции, зная типы аргументов

В динамических языках всё это определяется в рантайме, что добавляет накладные расходы.
