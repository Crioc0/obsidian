# Функции

Функции по сути своей- это подпрограмма, набор инструкций. Может иметь входные аргументы. Функция содержит локальные переменные и может возвращать результат.

Функция может запускать внутри себя другие функции(например, рекурсия). После того, как функция завершается, локальные данные должны освободить занимаемую память
```ts
// Аргументы a и b - это локальные данные
function sum(a, b) {
  return a + b;
  // Возвращаемое значение
}
// Аргументы x и y - это локальные данные
function multiply(x, y) {
  // Тоже локальные данные
  let result = 0;
  for (let i = 1; i <= y; i++) {
    result = sum(result, x);
    // Вложенный вызов функции
  }
  return result;
  // Возвращаемое значение
}
// Получили результат, а вся локальная память освобождается
console.log(multiply(2, 3));

```
