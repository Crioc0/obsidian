# Побитовое ИЛИ
Дает 1, если хотя бы один операнд 1
```js
0 | 0 == 0 
1 | 0 == 1 
0 | 1 == 1 
1 | 1 == 1
```

Благодаря побитовому ИЛИ можно объединять числа в одно число, например
```js
9 << 8 | 7 << 4 | 1
```
```js
	9 << 8 == 0b1001_0000_0000 
	7 << 4 == 0b0000_0111_0000 
	1 == 0b0000_0000_0001 
| 
		 0b1001_0111_0001 
```
Получилось число, внутри которого закодированы 3 BCD цифры

```js
// Мы можем закодировать некоторые признаки в виде чисел 
const CAN_READ = 0b0000_0001; 
const CAN_WRITE = 0b0000_0010; 
const CAN_DELETE = 0b0000_0100; 
// Теперь опишем роль, которая может читать и писать 
const editor = CAN_READ | CAN_WRITE; 

// Для проверки прав используем & 
if (role & CAN_READ) { 
// Данная роль умеет читать 
}
```
