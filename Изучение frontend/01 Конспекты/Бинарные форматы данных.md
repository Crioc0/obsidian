# Бинарные форматы данных

Бинарные форматы данных нужны везде, где нужно сэкономить память : JPEG, музыка, и прочее. Особенностью многих бинарных форматов данных являются специальные заголовки, в которых хранится метаинформация о данных, например, версия используемого формата или хэш-сумма для данных. Часто, это небольшая информация, для кодирования которой хватило всего бы несколько бит. Вместо того, чтобы каждому заголовку выделять отдельные байты - их можно упаковать внутри одного или нескольких байт.
