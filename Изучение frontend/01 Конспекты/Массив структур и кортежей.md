# Массив структур и кортежей

В отличие от массива, структура или кортеж могут хранить **разные типы** данных (гетерогенность). В памяти поля укладываются рядом, что позволяет статически вычислять смещения.

```ts
class Tuple {
  static readonly BYTES_PER_ELEMENT = 8;
  static getFirst(view: DataView, offset = 0, littleEndian = true): number {
    return view.getInt32(offset, littleEndian);
  }
  static setFirst(
    view: DataView,
    offset = 0,
    value: number,
    littleEndian = true,
  ) {
    view.setInt32(offset, value, littleEndian);
  }
  static getSecond(view: DataView, offset = 0, littleEndian = true): number {
    return view.getFloat32(offset + 4, littleEndian);
  }
  static setSecond(
    view: DataView,
    offset = 0,
    value: number,
    littleEndian = true,
  ) {
    view.setFloat32(offset + 4, value, littleEndian);
  }
}

```

### Разница между кортежем и структурой

| Понятие       | Доступ к полям                               | Пример                 |
| ------------- | -------------------------------------------- | ---------------------- |
| **Кортеж**    | Числовая индексация (первый, второй, третий) | `tuple[0]`, `tuple[1]` |
| **Структура** | Символьные имена                             | `point.x`, `point.y`   |

В бинарном представлении разница только в интерпретации — физически и то, и другое — последовательность байт

```ts
class TupleArray {
  readonly buffer: ArrayBuffer;
  readonly BYTES_PER_ELEMENT = Tuple.BYTES_PER_ELEMENT;
  readonly #view: DataView;
  constructor(length: number) {
    this.buffer = new ArrayBuffer(length * this.BYTES_PER_ELEMENT);
    this.#view = new DataView(this.buffer);
  }
  get(index: number): [number, number] {
    const i = this.#getIndex(index);
    return [Tuple.getFirst(this.#view, i), Tuple.getSecond(this.#view, i)];
  }
  set(index: number, value: [number, number]) {
    const i = this.#getIndex(index);
    Tuple.setFirst(this.#view, i, value[0]);
    Tuple.setSecond(this.#view, i, value[1]);
  }
  getFirst(index: number): number {
    return Tuple.getFirst(this.#view, this.#getIndex(index));
  }
  setFirst(index: number, value: number): void {
    Tuple.setFirst(this.#view, this.#getIndex(index), value);
  }
  getSecond(index: number): number {
    return Tuple.getSecond(this.#view, this.#getIndex(index));
  }
  setSecond(index: number, value: number): void {
    Tuple.setSecond(this.#view, this.#getIndex(index), value);
  }
  #getIndex(index: number) {
    return index * this.BYTES_PER_ELEMENT;
  }
}

```

### Паттерн DataView (view над данными)

**DataView** — это view, который позволяет читать/писать данные из ArrayBuffer без создания копий. Это паттерн, когда одна структура данных не владеет байтами, а предоставляет удобный интерфейс для работы с ними.

**Пример из жизни:** сервер отдал JSON, но не все поля нужны, или нужно добавить вычисляемое поле. Вместо копирования и создания нового объекта — создаём view, который читает исходные данные "на лету".

**В контексте бинарных данных:** DataView — способ читать и записывать разные типы (int32, float64, uint16) в один ArrayBuffer с контролем endianness.
