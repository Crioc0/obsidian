# Аналог частично примененной функции с помощью bind


## Что это? (Определение)
Применять bind для создания частично примененной функции не очень удобно, так как во-первых, bind первым аргументом принимает значение для аргумента this, во вторых, bind не вызывает функцию, а создает новую

Чтобы избавиться от явного вызова call, можно использовать [[Каррирование]]
 
## Для чего нужно
Используя call, можно абстрагироваться от того, что мы явно должны создавать частично примененную функцию. Можно проигнорировать избыточный для ФП this. Если аргументов придет меньше, чем ожидает функция, то вернется частично примененный вариант

## Улучшенный вариант
```ts
function call(fn,...args){
	if(fn.length > args.length)	{
		return fn.bind(null, ...args)
	}
	
	return fn(...args)
}

const sum = (a,b,c)=>a+b+c
const add42 = call(sum,10,32)

console.log(call(add42,10)); // 52
```
