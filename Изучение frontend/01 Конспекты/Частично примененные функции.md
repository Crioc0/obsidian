# Частично примененные функции


## Что это? (Определение)
Привычно воспринимать функции как единое целое: **набор аргументов, результат, возможность вызвать**
Например,
```js
sum = (a,b)=>a+b
```
Если нужна функция, добавляющая двойку, то делаем новую функция
```js
add2 = (a)=>a+2
```
В ФП принято создавать функцию с помощью частичного применения другой: 
```js
add2=sum(2)
```
Это не работает из коробки в JS.

## Как это работает? (Принцип)
В лямбда функция множества аргументов делается через возврат новой функции, например ![[Pasted image 20260129165059.png]]
Доступ к идентификаторам **x** и **y** получается с помощью замыкания.
Для этого можно ввести синтаксический сахар 
```js
(a,b)=>a + b == (a)=(b)=> a+b
```
Такое представление функций со множеством аргументов называется [[Каррирование| каррированием]]. Функция, которая поддерживает такую работу называется каррированной.
Результат вызова функций с неполным набором аргументов называется частично применённой функцией

Можно реализовать с помощью bind, но это не очень удобно. Можно сделать
