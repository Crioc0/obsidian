# Что такое шрифты

Шрифт — это набор правил, как превращать кодовые точки Unicode в визуальные изображения (глифы).

**Типы шрифтов:**

- **Bitmap fonts (растровые шрифты)** — каждый символ — это заранее нарисованная картинка фиксированного размера. Нельзя масштабировать без потери качества. Использовались в старых компьютерах и терминалах.
- **Vector fonts (векторные шрифты)** — каждый символ описан математическими кривыми (линии Безье). Можно масштабировать бесконечно без потери качества. Примеры: TrueType (.ttf), OpenType (.otf).

```css
/* Пример подключения шрифта в CSS */
@font-face {
    font-family: "CustomFont";
    src: url("custom-font.woff2") format("woff2");
    font-weight: normal;
    font-style: normal;
}

body {
    font-family: "CustomFont", "Arial", sans-serif;
    /* система будет использовать CustomFont, если он загрузился,
    иначе Arial, иначе любой sans-serif */
}
```

**Как работает загрузка шрифтов в браузере:**

1. Браузер загружает HTML и видит ссылку на CSS.
2. В CSS находит `@font-face` и начинает скачивать файл шрифта.
3. Пока шрифт не загрузился, текст отображается стандартным шрифтом (так называемый "Flash of Unstyled Text" или FOUT).
4. После загрузки шрифта текст перерисовывается.

Чтобы избежать скачков при перерисовке, используют свойство `font-display: swap` или предзагрузку шрифтов через `<link rel="preload">`.
