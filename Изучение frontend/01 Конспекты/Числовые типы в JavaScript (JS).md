# Числовые типы в JavaScript (JS)

JavaScript имеет два встроенных числовых типа:

- **number** — 64-битное число с плавающей точкой по стандарту IEEE 754 (двойная точность). Это единственный числовой тип в классическом JS.
- **bigint** — целое число произвольной точности. Добавлен в ECMAScript 2020.

**Особенности number:**

- Диапазон целых: от -2⁵³ до 2⁵³ (безопасные целые)
- Есть специальные значения: `Infinity`, `-Infinity`, `NaN` (Not a Number)
- Дробные числа могут представляться неточно
- Все операции с number происходят в 64-битной арифметике

**Особенности bigint:**

- Целые числа произвольной длины
- Обозначаются суффиксом `n`: `123n`, `BigInt("123")`
- Нельзя смешивать с number без явного преобразования
- Поддерживает только целочисленную арифметику

```js
const smallNumber = 42;              // number
const bigNumber = 9007199254740991n; // bigint

// Нельзя смешивать напрямую
// 42n + 1; // TypeError: Cannot mix BigInt and other types

// Нужно явное преобразование
42n + BigInt(1);  // 43n
Number(42n) + 1;  // 43
```
