# View-подход чтения данных

Альтернатива классической десериализации. Вместо того чтобы парсить весь файл в память, мы получаем "окошко" (view)прямо поверх переданных байтов. Популярным решением с таким подходом является Flatbuffers

**Как работает:** Данные в файле уже лежат в памяти в готовом виде. Специальная view-структура просто читает значения по нужным смещениям "на лету".

**Плюсы:** Мгновенный доступ к данным (время 0). Не нужно выделять память под кучи объектов.

**Минусы:** Данные в таком формате занимают больше места, так как их нужно заранее подготовить для "мгновенного чтения".

```js
// Пример data view в JavaScript (встроенный DataView)
const buffer = new ArrayBuffer(16);
const view = new DataView(buffer);

// Записываем разные типы данных в разные места
view.setInt32(0, 42, true);        // записываем 4 байта по смещению 0
view.setFloat64(4, 3.14159, true); // записываем 8 байт по смещению 4
view.setInt16(12, 100, true);      // записываем 2 байта по смещению 12

// Читаем данные мгновенно, без парсинга
console.log(view.getInt32(0, true));   // 42
console.log(view.getFloat64(4, true)); // 3.14159
console.log(view.getInt16(12, true));  // 100
```
