# День 4. Архитектура Vite

## Теория

Изучить официальный раздел:

### Почему Vite быстрый

Архитектура:

```text
Browser
   ↓
Native ES Modules
   ↓
Vite Dev Server
```

Ключевая идея:

Vite не собирает проект при старте.

---

### Две фазы работы

Development

```text
Source Files
      ↓
 On Demand Transform
```

Production

```text
Source Files
      ↓
 Rollup
      ↓
 Bundle
```

---

### Роль esbuild

Понять:

esbuild используется для:

- transpilation
- dependency pre-bundling

# День 5. Dependency Pre-Bundling

## Теория

Одна из самых важных тем.

```text

```

```js

```

# День 6. HMR (Hot Module Replacement)

## Теория

Изучить:

Что происходит при изменении файла.

### Без HMR

```text
Изменение файла
      ↓
Полная перезагрузка
```

### С HMR

```text
Изменение файла
      ↓
Обновление модуля
```

---

Изучить:

### HMR API

```js

}
```
